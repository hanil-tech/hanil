================================================================
  한일 TimeGuard — 직원 PC 설치 안내
================================================================

먼저 관리 서버를 설치해 두십시오. (서버설치안내.txt)
직원 PC 는 설치만 하면 사내망에서 서버를 알아서 찾습니다.



[ 1. 설치 — 파일 하나, 더블클릭 한 번 ]

  받으실 파일은 딱 하나입니다.

       TimeGuard-Setup.exe        (파란 시계 아이콘)

  설치에 필요한 모든 것이 이 안에 들어 있습니다.
  압축을 풀 것도, 다른 파일을 같이 둘 것도 없습니다.
  메신저나 USB 로 이 파일 하나만 보내시면 됩니다.

  1) TimeGuard-Setup.exe 를 더블클릭합니다.

  2) "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 가 뜨면 [예] 를 누릅니다.

  3) 설치 창이 뜹니다. 오른쪽 아래 [설치] 를 누릅니다.

  4) 진행 상황이 한 줄씩 올라가고, 끝나면
     "설치가 끝났습니다" 가 나옵니다.

     이 PC 이름과 확인 문자(8자리)가 함께 나옵니다.
     [PC 이름·확인 문자 복사] 를 누르면 그대로 복사됩니다.

  등록 키도, 서버 주소도 입력하지 않습니다.

  ※ 파란 화면으로 "Windows의 PC 보호" 가 뜨면
     [추가 정보] → [실행] 을 누르시면 됩니다.
     사내에서 만든 프로그램이라 서명이 없어서 그렇습니다.

  ※ 인터넷이나 메신저로 받은 파일이 안 열리면,
     파일 오른쪽 클릭 → [속성] → 아래쪽 [차단 해제] 체크 → [확인]

  ※ 여러 대를 한 번에 설치하려면 명령 프롬프트에서:
         TimeGuard-Setup.exe /설치


[ 2. 서버에서 승인 ]

  설치된 PC 는 스스로 서버에 "저 여기 있습니다" 하고 알립니다.

  1) 서버 웹 화면에 접속해 로그인합니다.

  2) [새 PC 승인] 메뉴에 방금 설치한 PC 가 나타납니다.
     메뉴 옆 빨간 숫자가 기다리는 PC 수입니다.

  3) PC 이름과 확인 문자가 설치할 때 본 값과 같은지 보고
     [승인] 을 누릅니다.

  4) 승인하면 그때부터 그 PC 에 시간표가 적용됩니다.
     [PC 목록] 으로 옮겨 갑니다.

  모르는 PC 가 올라와 있으면 [거절] 을 누르십시오.
  거절된 PC 는 아무 시간표도 받지 못합니다.


[ 3. 사용자에게 보이는 모습 ]

  - 작업 표시줄 오른쪽 끝에 TimeGuard 아이콘이 생깁니다.
    아이콘에 마우스를 올리면 남은 시간이 보입니다.
    아이콘을 클릭하면 자세한 안내가 뜹니다.

  - 종료 10분 전 / 5분 전 / 1분 전에 알림이 뜹니다.

  - 마지막 60초 동안 화면 가운데에 카운트다운 창이 뜹니다.
    이 창은 닫을 수 없습니다.

  - 시간이 다 되면 설정한 조치(전원 차단 또는 잠금)가 실행됩니다.

  - 직원이 더 써야 하면 아이콘에서 [연장 요청] 을 눌러
    사유를 적어 보냅니다. 서버 화면에서 승인하면 바로 풀립니다.


[ 4. 설정은 서버에서 합니다 ]

  시간표, 조치 방법, 연장 승인은 모두 서버 웹 화면에서 합니다.
  직원 PC 에서는 바꿀 수 없습니다. 그것이 이 방식의 목적입니다.

  서버에 연결된 PC 에서 TimeGuard.Admin.exe 로 설정을 바꾸려 하면
  "서버가 관리하는 PC 입니다" 라고 거절합니다.


[ 5. 현재 상태 확인 ]

  TimeGuard-Setup.exe 를 다시 실행하면 첫 화면에 바로 나옵니다.
    · 설치 여부와 서비스 상태
    · 연결된 서버 주소와 승인 상태
    · 이 PC 의 확인 문자

  프로그램을 최신으로 바꾸려면 [다시 설치] 를 누릅니다.
  설정과 기록, 서버 등록 상태는 그대로 유지됩니다.


[ 6. 문제가 생겼을 때 ]

  서비스가 도는지 확인
    → 명령 프롬프트에서:  sc query HanilTimeGuard
    → STATE 가 RUNNING 이어야 합니다.

  서버를 못 찾는 것 같을 때
    → 서버 PC 가 켜져 있는지, 같은 사내망인지 확인합니다.
    → 서버를 못 찾아도 마지막으로 받은 시간표는 계속 적용됩니다.

  [새 PC 승인] 화면에 나타나지 않을 때
    → 대개 서버 PC 의 네트워크가 [공용] 으로 잡혀 있어서입니다.
       방화벽이 사내망에만 열리므로 [공용] 이면 막힙니다.

       서버 PC 에서:
         [설정] → [네트워크 및 인터넷] → 연결된 네트워크를 누르고
         네트워크 프로필을 [개인] 으로 바꿉니다.

    → 그 밖에 확인할 것
         · 서버 PC 가 켜져 있는지
         · 두 PC 가 같은 사내망에 있는지
         · 클라이언트 기록에 "관리 서버를 찾는 중입니다" 가 있는지
           (C:\ProgramData\HanilTimeGuard\timeguard.log)

    → 서버를 나중에 켜셔도 됩니다.
       직원 PC 가 계속 찾고 있다가 서버가 켜지면 알아서 나타납니다.

  설치가 실패했을 때
    → 빨간 글씨로 실패 화면이 나오면, 거기에 적힌
       진행 기록 파일 위치를 확인해 주십시오.
       [진행 기록 복사] 를 눌러 붙여넣으셔도 됩니다.
       그 내용을 보내 주시면 어디서 멈췄는지 알 수 있습니다.

    → 가장 흔한 원인
         · 백신 프로그램이 막는다  → 잠시 끄고 다시
         · 프로그램이 아직 돌고 있다  → PC 를 다시 켜고 다시

  설치 중 오류 창이 떴을 때
    → 창에 적힌 파일 위치를 확인합니다.
       보통 C:\Users\<사용자>\AppData\Local\Temp\ 안에
       TimeGuard-설치오류-날짜.txt 로 저장됩니다.
    → 그 파일을 보내 주시면 원인을 찾을 수 있습니다.

  기록 파일 위치
    → C:\ProgramData\HanilTimeGuard\timeguard.log

  설정 파일 위치
    → C:\ProgramData\HanilTimeGuard\config.json


[ 7. 제거 ]

  TimeGuard-Setup.exe 를 실행해 왼쪽 아래 [제거] 단추를 누릅니다.

  제거하면 함께 되돌아가는 것들
    · 잠겨 있던 Windows 계정이 풀립니다
    · 막아 두었던 원격 접속 설정이 되돌아갑니다
    · 시작 프로그램 등록이 지워집니다

  서버 [PC 목록] 에서도 그 PC 를 지워 주십시오.
