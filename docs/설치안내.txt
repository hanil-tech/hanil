================================================================
  한일 TimeGuard — 직원 PC 설치 안내
================================================================

먼저 관리 서버를 설치해 두십시오. (서버설치안내.txt)
직원 PC 는 설치만 하면 사내망에서 서버를 알아서 찾습니다.


[ 1. 설치 — 더블클릭 한 번 ]

  1) 압축을 풀어 폴더 전체를 직원 PC 에 복사합니다.
     (USB, 공유 폴더, 메일 무엇이든 됩니다)

  2) 폴더 안의 아래 파일을 더블클릭합니다.

       TimeGuard-설치.exe

  3) "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 가 뜨면 [예] 를 누릅니다.

  4) 검은 창에서 [1] 설치 를 누릅니다.

  5) "설치가 끝났습니다" 가 나오면 됩니다.
     화면에 이 PC 이름과 확인 문자가 나옵니다. 잠깐 적어 두십시오.

  ※ 등록 키를 넣거나 명령을 입력할 일은 없습니다.
  ※ 여러 대를 한 번에 설치하려면 명령 프롬프트에서:
         TimeGuard-설치.exe /설치


[ 2. 서버에서 승인 ]

  설치된 PC 는 스스로 서버에 "저 여기 있습니다" 하고 알립니다.

  1) 서버 웹 화면에 접속해 로그인합니다.

  2) [새 PC 승인] 메뉴에 방금 설치한 PC 가 나타납니다.
     메뉴 옆 빨간 숫자가 기다리는 PC 수입니다.

  3) PC 이름과 확인 문자가 설치할 때 본 값과 같은지 보고
     [승인] 을 누릅니다.

  4) 승인하면 그때부터 그 PC 에 시간표가 적용됩니다.
     [PC 목록] 으로 옮겨 갑니다.

  모르는 PC 가 올라와 있으면 [거절] 을 누르십시오.
  거절된 PC 는 아무 시간표도 받지 못합니다.


[ 3. 사용자에게 보이는 모습 ]

  - 작업 표시줄 오른쪽 끝에 TimeGuard 아이콘이 생깁니다.
    아이콘에 마우스를 올리면 남은 시간이 보입니다.
    아이콘을 클릭하면 자세한 안내가 뜹니다.

  - 종료 10분 전 / 5분 전 / 1분 전에 알림이 뜹니다.

  - 마지막 60초 동안 화면 가운데에 카운트다운 창이 뜹니다.
    이 창은 닫을 수 없습니다.

  - 시간이 다 되면 설정한 조치(전원 차단 또는 잠금)가 실행됩니다.

  - 직원이 더 써야 하면 아이콘에서 [연장 요청] 을 눌러
    사유를 적어 보냅니다. 서버 화면에서 승인하면 바로 풀립니다.


[ 4. 설정은 서버에서 합니다 ]

  시간표, 조치 방법, 연장 승인은 모두 서버 웹 화면에서 합니다.
  직원 PC 에서는 바꿀 수 없습니다. 그것이 이 방식의 목적입니다.

  서버에 연결된 PC 에서 TimeGuard.Admin.exe 로 설정을 바꾸려 하면
  "서버가 관리하는 PC 입니다" 라고 거절합니다.


[ 5. 현재 상태 확인 ]

  TimeGuard-설치.exe 를 다시 실행하면 첫 화면에 나옵니다.
    · 설치 여부와 서비스 상태
    · 연결된 서버 주소와 승인 상태

  [2] 현재 상태 보기 를 누르면 더 자세히 볼 수 있습니다.


[ 6. 문제가 생겼을 때 ]

  서비스가 도는지 확인
    → 명령 프롬프트에서:  sc query HanilTimeGuard
    → STATE 가 RUNNING 이어야 합니다.

  서버를 못 찾는 것 같을 때
    → 서버 PC 가 켜져 있는지, 같은 사내망인지 확인합니다.
    → 서버를 못 찾아도 마지막으로 받은 시간표는 계속 적용됩니다.

  기록 파일 위치
    → C:\ProgramData\HanilTimeGuard\timeguard.log

  설정 파일 위치
    → C:\ProgramData\HanilTimeGuard\config.json


[ 7. 제거 ]

  TimeGuard-설치.exe 를 실행해 [3] 제거 를 누릅니다.

  제거하면 함께 되돌아가는 것들
    · 잠겨 있던 Windows 계정이 풀립니다
    · 막아 두었던 원격 접속 설정이 되돌아갑니다
    · 시작 프로그램 등록이 지워집니다

  서버 [PC 목록] 에서도 그 PC 를 지워 주십시오.
