================================================================
  한일 TimeGuard — 설치 안내
================================================================

[ 1. 설치 ]

  1) 이 폴더 전체를 대상 PC 에 복사합니다.

  2) 시작 메뉴에서 "PowerShell" 을 찾아
     마우스 오른쪽 클릭 → [관리자 권한으로 실행] 을 선택합니다.

  3) 복사한 폴더로 이동한 뒤 아래를 입력합니다.

       powershell -ExecutionPolicy Bypass -File .\install.ps1

  4) "설치가 끝났습니다" 가 나오면 완료입니다.


[ 2. 설정 — 반드시 해야 합니다 ]

  설치 직후에는 감시가 꺼져 있어 아무도 제한받지 않습니다.
  아래 순서대로 설정을 마쳐야 실제로 동작합니다.

  1) 아래 파일을 실행합니다.
       C:\Program Files\HanilTimeGuard\TimeGuard.Admin.exe

  2) 메뉴에서 순서대로 진행합니다.

       [10] 관리자 비밀번호 변경
            → 8자 이상, 숫자만은 안 됩니다.
            → 이 비밀번호가 없으면 감시를 켤 수 없습니다.

       [2]  허용 시간대 설정
            → [2] 평일 한 번에 지정  →  09:00-18:00
            → [4] 주말 사용 금지
            → [0] 저장하고 돌아가기

       [9]  제한 제외 계정 관리   (권장)
            → 관리자 계정을 등록해 두면 관리자는 제한받지 않습니다.

       [4]  시간 초과 시 조치
            → [1] 전원 차단

       [3]  감시 켜기
            → 여기서 "y" 를 입력하면 이때부터 동작합니다.


[ 3. 사용자에게 보이는 모습 ]

  - 작업 표시줄 오른쪽 끝에 TimeGuard 아이콘이 생깁니다.
    아이콘에 마우스를 올리면 남은 시간이 보입니다.
    아이콘을 클릭하면 자세한 안내가 뜹니다.

  - 종료 10분 전 / 5분 전 / 1분 전에 알림이 뜹니다.

  - 마지막 60초 동안 화면 가운데에 카운트다운 창이 뜹니다.
    이 창은 닫을 수 없습니다.

  - 시간이 다 되면 컴퓨터가 꺼집니다.


[ 4. 자주 쓰는 기능 ]

  야근으로 오늘만 더 써야 할 때
    → 관리자 도구 [6] 임시 연장 부여 → 분 단위로 입력

  프로그램 설치 등으로 잠시 꺼지면 안 될 때
    → 관리자 도구 [7] 일시 중지 → 분 단위로 입력

  언제 꺼졌는지 확인하고 싶을 때
    → 관리자 도구 [11] 기록 보기


[ 5. 문제가 생겼을 때 ]

  서비스가 도는지 확인
    → 명령 프롬프트에서:  sc query HanilTimeGuard
    → STATE 가 RUNNING 이어야 합니다.

  서비스를 다시 시작
    → 관리자 권한 명령 프롬프트에서:
         net stop HanilTimeGuard
         net start HanilTimeGuard

  기록 파일 위치
    → C:\ProgramData\HanilTimeGuard\timeguard.log

  설정 파일 위치
    → C:\ProgramData\HanilTimeGuard\config.json


[ 6. 제거 ]

  관리자 권한 PowerShell 에서:

    powershell -ExecutionPolicy Bypass -File .\uninstall.ps1

  설정과 기록을 남기려면 뒤에 -KeepSettings 를 붙입니다.
