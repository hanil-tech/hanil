# ☀️ 태양광 발전 화면 — 포털에 넣어 주세요 (포털 개발용 요청서)

> 한일특장 포털(work.hanil-steel.com, `/data/portal`)의 **다음 버전에 정식 기능으로** 넣기 위한 문서입니다.
> 지금은 포털 밖(`~/solar`)에서 server.js 에 한 줄을 끼워 넣는 임시 방식이라, 포털을 업그레이드하면 빠집니다.
> 이 문서대로 포털 소스에 넣으면 업그레이드해도 유지됩니다.

## 1. 무엇을 하는 기능인가
- 회사 태양광 발전소(**한일특장1호**, 400kW, 완주군 봉동읍)의 발전량을 **에너지어스 VPP**(www.energyus-vppc.com) 사이트에서 회사 계정으로 가져옵니다.
- 포털이 켜져 있는 동안 **10분마다** 자동으로 가져와서 저장합니다. cron 은 쓰지 않습니다.
- `/solar` 화면에 보여 주는 것:
  - 지금 발전(kW)
  - 오늘·어제·이번 달·누적 발전량(kWh)
  - 발전시간
  - 오늘 시간대별 그래프와 최근 30일 막대그래프
  - 발전소 상태
- 발전소 고장, 통신 끊김, 사이트에서 3번 연속 못 가져옴 → **NOPS 알림**. 정상으로 돌아오면 「정상 복귀」 알림도 보냅니다.

## 3. server.js 에 붙이기
세션이 붙은 뒤, `require('./faxbox')` 줄 옆에 넣습니다.
```js
require('./solar-route')(app, {
  passFile: '/home/gaos/.vpp-pass',          // 1줄: VPP 아이디(이메일), 2줄: 비밀번호. chmod 600. 이미 서버에 있음
  dir: '/data/portal/data/solar',            // 저장 위치 (기본 ~/solar/data — 지금 쌓인 기록은 거기 있음, 옮기거나 그대로 지정)
  everyMin: 10,                              // 가져오는 간격(분)
  view: (u) => true,                         // 누가 보나 — 아래 4. 권한 참고
  user: (req) => { /* 포털 방식으로 { id, admin } 돌려주기 — 아래 4. */ },
  notify: (msg, url) => nopsPush(관리자아이디, msg),   // 이상·복귀 알림
});
```
- 저장 파일:
  - `latest.json`: 마지막 값
  - `daily.json`: 날짜별 kWh·최대 kW·발전시간
  - `days/YYYY-MM-DD.jsonl`: 10분 간격 기록
- 모두 바꿔치기(.tmp → rename) 방식으로 써서, 중간에 꺼져도 깨지지 않습니다.
- ⚠ **지금 서버에는 임시 방식이 깔려 있습니다.** 정식으로 넣은 뒤에는 아래를 실행해서 임시 방식을 빼 주세요. 빼지 않으면 두 번 붙습니다.
  ```bash
  bash ~/solar/portal-addons.sh --uninstall
  ```
  이 명령은 systemd drop-in `hanil-portal.service.d/hanil-addons.conf` 를 지우고, server.js 의 `// ☀️ 태양광 (patch-portal-solar)` 줄을 뺍니다.
  같은 drop-in 이 **팩스 자동 AI 판독**(`faxbox.js` 의 `>>> 자동 AI 판독 (patch-faxbox-autoread)` 블록)도 다시 넣고 있습니다. 그 기능도 faxbox.js 에 정식으로 넣어 주세요 (§7).

## 4. 메뉴와 권한 — server.js 네 곳에 `solar` 한 줄씩
포털 메뉴는 key 로 묶여 있습니다. sessions.json 의 직원 권한이 `"fax":1, "checklist":1, "appdl":1 …` 모양입니다. 지금 서버의 줄 번호(v17.9x) 기준으로, `appdl`·`fax` 항목과 **같은 모양으로** `solar` 를 넣어 주세요.

| 위치 (현재 줄) | 있는 것 | 넣을 것 |
|---|---|---|
| ~4748 메뉴·권한 목록 | `{ key: 'appdl', label: '폰 앱 받기', def: 1, url: '/app' },` | `{ key: 'solar', label: '태양광 발전', def: 1, url: '/solar' },` |
| ~4807 아이콘 표 | `… fax: '📠', appdl: '📲' …` | `solar: '☀️',` |
| ~5767 메뉴 묶음 | `… 'appdl'] },` | 알맞은 묶음(예: 경영·현황, 없으면 fax 와 같은 묶음)에 `'solar'` |
| ~5937 다른 메뉴 목록 (폰/시작 화면) | `{ key: 'appdl', url: '/app', icon: '📲', label: '폰 앱 받기' },` | `{ key: 'solar', url: '/solar', icon: '☀️', label: '태양광 발전' },` |

- `def: 1`: 처음부터 모두에게 보입니다. 관리자만 보게 하려면 `def: 0` 으로 하고 「직원 계정 관리」 에서 권한을 줍니다.
- solar-route 의 권한 확인도 포털의 권한 칸을 따르게 해 주세요.
  - `view: (u) => 포털의권한확인(u, 'solar')`
  - `user: (req) => ({ id: req.session.user.아이디, admin: freshRole(req) === 'admin' })`
  - 기본 `user` 함수는 `req.session.user` 의 username·id 와 role==='admin' 을 봅니다.
- 화면 왼쪽 위 「← 포털」 링크는 `/` 로 갑니다. 포털 공통 머리말(메뉴 막대)이 있으면 solar-page.html 에 같은 머리말을 넣거나, solar-page.html 의 `<div class="wrap">` 안쪽을 포털 레이아웃에 담아 주세요.

## 5. API (모두 로그인 필요)
| 주소 | 내용 |
|---|---|
| `GET /solar` | 화면 (로그인 안 했으면 `/?next=/solar`) |
| `GET /api/solar/latest` | `{ at, overview, plants[], alerts[], error?, everyMin, admin }` |
| `GET /api/solar/today?date=YYYY-MM-DD` | 그날 10분 기록 `[{t, kw, kwh}]` |
| `GET /api/solar/daily?days=30` | 날짜별 `[{date, kwh, peakKw, hours}]` |
| `POST /api/solar/refresh` | 지금 바로 가져오기 (관리자만) |

메뉴 옆에 숫자나 점을 붙이려면 `/api/solar/latest` 를 쓰면 됩니다. 예를 들어 `alerts.length > 0` 이면 빨간 점, 아니면 `overview.nowKw` kW 를 보여 줍니다.

## 6. VPP 사이트 정보 (2026-11-14, 실제 응답으로 확인)
- 주소: `https://www.energyus-vppc.com/tws`. 세션 쿠키 방식입니다.
- `POST /any/login {identity, password}` → `{ok:true}`
- `GET /stats/overview` →
  - `qty, normalQty, faultQty, checkQty, offlineQty`
  - `nomActPower`(kW)
  - `daiPowYields`, `monthPowYields`, `totPowYields`(kWh)
  - `totalCapacity`(kW)
  - `monthAvgDevTime`(h)
- `GET /stats/power/plants` → 발전소 배열. 각 항목:
  - `tid, name, capacity, addr`
  - `nomActPower, daiPowYields, totPowYields`
  - `daiDevTime`(오늘 발전시간)
  - `previousPower`(어제 kWh), `previousDevTime`
  - `powerFactor`
  - `plantSts`(normal…), `iotSts`(on/off), `derRtuSts`(on/off)
- `tid` 는 JS 안전 정수(2^53)에 가까운 큰 수입니다. 화면에는 문자열로 넘깁니다.
- `/master/plants/{tid}/things`(장비 목록)는 이 계정에서 빈 배열이라 쓰지 않습니다.
- 계정: 서버 `/home/gaos/.vpp-pass` (권한 600). **소스나 문서에 비밀번호를 넣지 마세요.**

## 7. 함께 정식으로 넣어 주면 좋은 것 — 팩스 자동 AI 판독
- 파일: `fax/portal/patch-faxbox-autoread.js` 가 faxbox.js 에 넣는 블록입니다.
- 동작:
  - 1분마다 아직 판독하지 않은 새 받은 팩스를 한 장씩 판독합니다. 「읽기」 단추와 같은 `readFax(f, {})` → `saveText(f, r)` 입니다.
  - 한 팩스는 한 번만 시도합니다 (`auto_read_at`).
  - 기존 팩스는 건드리지 않습니다 (`AUTO_READ_SINCE`).
- 정식으로 넣을 때는 `AUTO_READ_SINCE` 를 「기능을 처음 켠 시각」 설정값으로 저장해 주세요. 업그레이드할 때마다 바뀌면 안 됩니다.
