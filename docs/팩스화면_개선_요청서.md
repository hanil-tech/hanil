# 📠 팩스 화면 개선 — 포털 개발 요청서

> 대상: 포털 「문서·소통 › 팩스」 화면 (`/fax`, `faxbox.js` + `public/fax.html`)
> 요청일: 2026-11-24 · 요청: 사장님
> 서버에서 직접 고치면 포털을 업그레이드할 때 되돌아갑니다. **다음 버전 소스에 넣어 주세요.**

---

## 1. 「안 봄」 → 「미확인」 으로 이름 바꾸기
| 지금 | 바꿀 것 |
|---|---|
| 왼쪽 위 상태 탭 「안 봄 17」 | **「미확인 17」** |
| 새 팩스 알림 「새 팩스 14건이 왔습니다」 | 그대로 둠 (누르면 「미확인」 탭으로) |

- 다른 탭(확인 · 처리 완료 · 전체)은 그대로 둡니다.
- 화면에 「안 봄」 이 쓰인 곳(탭, 빈 목록 안내, 툴팁, 설명서 manual.html)을 모두 「미확인」 으로 맞춰 주세요.
- 내부 상태 값(예: `new`)은 바꾸지 않아도 됩니다. **보이는 글자만** 바꾸면 됩니다.

## 2. 미확인 팩스를 눌러도 목록이 바로 바뀌지 않게 (깜빡임 없애기)
### 지금 문제
「미확인」 탭에서 팩스를 누르면 그 순간 상태가 「확인」 으로 바뀝니다. 그래서 다음 일이 한꺼번에 일어납니다.
- 그 팩스가 목록에서 바로 사라집니다.
- 아래 항목이 위로 올라옵니다.
- 숫자가 바뀌고 화면이 다시 그려집니다.

그 결과 **화면이 깜빡이고**, 보던 자리를 잃고, 다음 팩스를 누르려다 엉뚱한 팩스를 누르게 됩니다.

### 바꿀 동작
1. 팩스를 누르면 **오른쪽에 내용만 연다.** 상태는 아직 「미확인」 입니다.
2. **5초 동안 계속 열어 두면** 그때 「확인」 으로 바꿉니다. 5초 안에 다른 팩스로 넘어가면 바꾸지 않습니다. 훑어보기만 한 것은 미확인으로 남깁니다.
3. 「확인」 으로 바뀌어도 **지금 보고 있는 미확인 목록에서는 빼지 않습니다.**
   - 목록 줄은 그 자리에 그대로 둡니다.
   - 빨간 점만 회색으로 바꾸고, 글자를 조금 흐리게 합니다.
   - 위쪽 숫자(미확인 14 → 13, 확인 252 → 253)는 바로 바꿔도 됩니다. 숫자는 깜빡임을 일으키지 않습니다.
4. 줄이 실제로 목록에서 빠지는 것은 아래 경우뿐입니다.
   - 다른 탭을 눌렀다가 돌아왔을 때
   - ↻(새로고침)을 눌렀을 때
   - 화면을 다시 열었을 때
5. 「처리 완료」 단추를 누른 경우는 지금처럼 바로 처리합니다. 다만 이때도 줄을 바로 지우지 말고 흐리게만 해 두면 좋습니다.

### 구현 메모 (참고)
```js
let viewTimer = null;
function openFax(f) {
  showFax(f);                                   // 내용만 보여 준다 (목록은 다시 그리지 않음)
  clearTimeout(viewTimer);
  if (f.status === 'new') {
    viewTimer = setTimeout(async () => {
      await api.put('/api/fax/' + f.id, { status: 'seen' });   // 서버 상태만 바꾼다
      f.status = 'seen';
      markRowSeen(f.id);                        // 그 줄만 흐리게 (목록 전체를 다시 그리지 않음)
      updateCounts(-1, +1);                     // 위쪽 숫자만 고침
    }, 5000);
  }
}
```
- 지금 「열어 봄」 기록(예: `오늘 14:08 장병우 – 열어 봄`)은 그대로 남겨 주세요. 기록은 5초 뒤 「확인」 으로 바뀔 때 함께 남기면 됩니다.
- 2분마다 새 팩스를 가져와서 목록을 다시 그리는 동작이 있으면, **보고 있는 줄의 위치를 유지**하게 해 주세요. 새 팩스는 맨 위에 끼워 넣고, 스크롤 위치와 선택한 팩스는 그대로 둡니다.

## 3. 보낸 번호가 없는 팩스의 제목이 「2026년 (unknown)」 으로 나옴
### 원인
- 받은 팩스 파일은 NAS `80_받은팩스/admin/2026년/` 처럼 **연도 폴더** 안에 들어 있습니다.
- 포털은 FaxBox 방식(「보낸 곳별 폴더」)을 따라, **바로 위 폴더 이름을 보낸 곳 이름**으로 씁니다. 그래서 번호가 없는 팩스는 이름이 「2026년」, 번호가 「unknown」 으로 나옵니다.

### 바꿀 동작
- 폴더 이름이 `^\d{4}년$` (연도 폴더)이면 보낸 곳 이름으로 쓰지 않습니다.
- 번호가 `unknown` · `unknow` · 빈 값이면 화면에는 **「번호 모름」** 으로 표시합니다. 목록에는 이미 그렇게 나오니, 제목도 똑같이 맞춰 주세요.
- 내려받기 파일 이름도 같은 원칙으로 짓습니다. 지금 `팩스_20261119_1526_2026년.pdf` 를 `팩스_20261119_1526_번호모름.pdf` 로 바꿔 주세요.

## 확인 방법
1. 「미확인」 탭에서 팩스를 눌러 1초 만에 다음 팩스로 넘어간다 → 첫 팩스는 **미확인 그대로**, 목록이 움직이지 않아야 합니다.
2. 한 팩스를 5초 넘게 열어 둔다 → 숫자는 미확인 −1, 확인 +1로 바뀌고, **줄은 흐려진 채 그 자리에** 남아야 합니다.
3. 「확인」 탭에 갔다가 「미확인」 탭으로 돌아온다 → 그 팩스가 미확인 목록에서 빠져 있어야 합니다.
4. 번호가 없는 팩스(예: 2026-11-19 15:26 출국만기보험 안내)를 연다 → 제목에 「번호 모름」 이 나와야 합니다.
