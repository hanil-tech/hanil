================================================================
  한일 TimeGuard 관리 서버 — 설치 안내
================================================================

이 서버는 직원 PC 들의 사용 시간표를 한곳에서 관리합니다.
직원이 자기 PC 에서 시간표를 바꿀 수 없게 하는 것이 목적입니다.


[ 어디에 설치하나 ]

  사무실 PC 나 서버 한 대를 정해 설치합니다.
  그 PC 는 업무 시간 동안 켜 두어야 합니다.

  꺼져 있어도 직원 PC 는 마지막으로 받은 시간표를 그대로 적용하므로
  제한이 풀리지는 않습니다. 다만 연장 승인은 서버가 켜져 있어야 됩니다.


[ 1. 설치 ]

  1) 이 폴더 전체를 서버로 쓸 PC 에 복사합니다.

  2) PowerShell 을 [관리자 권한으로 실행] 합니다.

  3) 복사한 폴더로 이동한 뒤 입력합니다.

       powershell -ExecutionPolicy Bypass -File .\install-server.ps1

     다른 포트를 쓰려면:

       powershell -ExecutionPolicy Bypass -File .\install-server.ps1 -Port 9000

  4) 화면에 나오는 접속 주소와 최초 로그인 정보를 적어 둡니다.


[ 2. 첫 설정 ]

  1) 웹 브라우저에서 설치 시 안내된 주소로 접속합니다.
       예: http://192.168.0.10:8080

  2) 아이디 admin 과 임시 비밀번호로 로그인합니다.
     임시 비밀번호는 아래 파일에도 적혀 있습니다.
       C:\ProgramData\HanilTimeGuardServer\최초설정정보.txt

  3) [설정] → 관리자 비밀번호를 바꿉니다.
     바꾼 뒤 위 파일은 삭제하십시오.

  4) [기본 시간표] → 허용 시간대를 지정합니다.
       예: 월~금 09:00-18:00, 토·일 없음

  5) [설정] → 클라이언트 등록 키를 확인해 적어 둡니다.
     직원 PC 에 클라이언트를 설치할 때 필요합니다.


[ 3. 직원 PC 연결 ]

  직원 PC 마다 클라이언트를 설치한 뒤, 관리자 권한 명령 프롬프트에서:

    "C:\Program Files\HanilTimeGuard\TimeGuard.Admin.exe" enroll ^
        --server http://192.168.0.10:8080 ^
        --key ABCDE-FGHIJ-KLMNO-PQRST

    net stop HanilTimeGuard
    net start HanilTimeGuard

  등록되면 서버의 [PC 목록] 에 나타납니다.


[ 4. 평소 사용 ]

  PC 목록      각 PC 의 현재 상태와 마지막 연결 시각을 봅니다.
  PC 상세      그 PC 만 다른 시간표를 주거나, 즉시 연장·중지할 수 있습니다.
  연장 요청    직원이 올린 요청을 승인하거나 거절합니다.
               요청한 것보다 적게 줄 수도 있습니다.
  기본 시간표  전용 시간표를 쓰지 않는 모든 PC 에 적용됩니다.
  기록         언제 어느 PC 가 꺼졌는지 확인합니다.


[ 5. 알아 두실 점 ]

  · "연결 끊김" 으로 표시되는 PC 는 꺼져 있거나, 랜선이 빠졌거나,
    누군가 서비스를 멈춘 경우입니다. 이 경우에도 그 PC 는
    마지막으로 받은 시간표를 계속 적용합니다.

  · 직원 계정이 Windows 관리자 권한을 갖고 있으면 서비스를 멈출 수 있습니다.
    직원 계정은 일반 사용자로 두시는 것을 권합니다.
    서비스를 멈추더라도 서버 화면에 "연결 끊김" 으로 남아 확인할 수 있습니다.

  · 사내망 안에서만 접속하도록 방화벽이 설정됩니다.
    외부에서 접속해야 한다면 별도 조치가 필요합니다.


[ 6. 백업 ]

  아래 파일 하나에 모든 설정과 기록이 들어 있습니다.

    C:\ProgramData\HanilTimeGuardServer\timeguard.db

  서버를 잠시 멈춘 뒤 복사해 두시면 됩니다.

    net stop HanilTimeGuardServer
    copy "C:\ProgramData\HanilTimeGuardServer\timeguard.db" D:\백업\
    net start HanilTimeGuardServer


[ 7. 문제가 생겼을 때 ]

  서버가 도는지 확인
    sc query HanilTimeGuardServer

  다시 시작
    net stop HanilTimeGuardServer
    net start HanilTimeGuardServer

  직접 실행해 오류 보기 (관리자 권한 명령 프롬프트)
    "C:\Program Files\HanilTimeGuardServer\TimeGuard.Server.exe"


[ 8. 제거 ]

    powershell -ExecutionPolicy Bypass -File .\uninstall-server.ps1

  자료를 남기려면 뒤에 -KeepData 를 붙입니다.

  주의: 서버를 지워도 직원 PC 의 제한은 그대로 유지됩니다.
        각 PC 에서 아래를 실행해야 풀립니다.
          TimeGuard.Admin.exe unenroll
