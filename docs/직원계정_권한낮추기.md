# 직원 계정 권한 낮추기

TimeGuard 로 막아 둔 것들은 **직원 계정이 일반 사용자일 때** 제대로 듣습니다.
직원 계정에 관리자 권한이 있으면 서비스를 멈춰 전부 무력화할 수 있습니다.
(흔적은 서버에 남지만, 그때는 이미 늦습니다.)

이 문서는 그 작업을 순서대로 안내합니다. **PC 한 대에 10분이면 됩니다.**

> **가장 중요한 것**
> 순서를 지키십시오. 관리자 계정을 먼저 확보하지 않고 직원 계정을 낮추면
> **그 PC 에서 아무것도 못 하게 됩니다.** 2단계를 건너뛰지 마십시오.

---

## 왜 해야 하나

| 직원 계정이 관리자면 | 일반 사용자면 |
|---|---|
| 서비스를 멈출 수 있음 → 시간 제한 무력화 | 멈출 수 없음 |
| 프로그램을 지울 수 있음 | 지울 수 없음 |
| 설정 파일을 고칠 수 있음 | 읽기만 가능 |
| 원격 제어 프로그램을 마음대로 설치 | 설치하려면 관리자 승인 필요 |
| 계정 잠금이 적용되지 않음 (안전장치) | 적용됨 |

마지막 줄이 특히 중요합니다. **관리자 권한 계정에는 계정 잠금이 걸리지 않습니다.**
PC 를 되돌릴 방법이 사라지기 때문에 일부러 그렇게 만들어 두었습니다.
즉 직원이 관리자면 가장 강한 조치가 아예 동작하지 않습니다.

---

## 1단계 — 지금 상태 확인

먼저 이 PC 의 계정들이 어떤 상태인지 봅니다.

**방법 A. TimeGuard 로 확인 (가장 쉬움)**

관리 서버의 **PC 목록** 화면을 보십시오.
관리자 권한으로 로그인한 PC 는 **"관리자 권한"** 이라고 빨갛게 표시됩니다.
그 PC 들만 작업하면 됩니다.

**방법 B. 해당 PC 에서 직접 확인**

명령 프롬프트(`cmd`)를 열고:

```
net localgroup Administrators
```

여기 나오는 이름들이 관리자 권한을 가진 계정입니다.
직원 계정 이름이 보이면 낮춰야 합니다.

---

## 2단계 — 관리자 계정 확보 (건너뛰지 마십시오)

직원 계정을 낮추기 **전에**, 관리자로 쓸 계정이 따로 있어야 합니다.
없으면 그 PC 에서 아무 설정도 못 하게 됩니다.

### 이미 있는 경우

1단계에서 본 목록에 `Administrator` 나 회사 관리용 계정이 있고,
**그 비밀번호를 알고 있다면** 3단계로 넘어가십시오.

> `Administrator` 계정은 기본으로 꺼져 있는 경우가 많습니다.
> 켜져 있는지 확인하려면: `net user Administrator`
> "계정 활성" 이 `Yes` 여야 씁니다.

### 새로 만드는 경우

관리자 권한 명령 프롬프트에서 (시작 → `cmd` 입력 → 오른쪽 클릭 → 관리자 권한으로 실행):

```
net user 회사관리자 원하는비밀번호 /add
net localgroup Administrators 회사관리자 /add
```

- 계정 이름은 알아보기 쉬운 것으로 하십시오 (예: `회사관리자`, `itadmin`)
- **비밀번호는 직원이 모르는 것으로** 정하십시오
- 모든 PC 에 같은 이름·같은 비밀번호로 만들어 두면 관리가 편합니다

### 반드시 확인하십시오

**지금 로그아웃하고 새 관리자 계정으로 로그인해 보십시오.**

로그인이 되고, 명령 프롬프트를 관리자 권한으로 열 수 있으면 됐습니다.
**이걸 확인하기 전에는 절대 3단계로 넘어가지 마십시오.**

---

## 3단계 — 직원 계정 낮추기

새로 만든 관리자 계정으로 로그인한 상태에서, 관리자 권한 명령 프롬프트에:

```
net localgroup Administrators 직원계정이름 /delete
```

예를 들어 직원 계정 이름이 `hong` 이면:

```
net localgroup Administrators hong /delete
```

`명령을 잘 실행했습니다` 가 나오면 끝입니다.

### 화면으로 하고 싶다면

**Windows 10 / 11 공통**

1. 시작 → `netplwiz` 입력 → Enter
2. 직원 계정을 고르고 **[속성]**
3. **[그룹 구성원 자격]** 탭
4. **[표준 사용자]** 선택 → [확인]

**Windows Pro 버전이라면 이 방법도 됩니다**

1. 시작 → `lusrmgr.msc` 입력 → Enter
2. **사용자** → 직원 계정 두 번 클릭
3. **[소속 그룹]** 탭 → `Administrators` 선택 → [제거] → [확인]

---

## 4단계 — 확인

직원 계정으로 다시 로그인한 뒤:

```
net localgroup Administrators
```

직원 계정 이름이 **없어야** 합니다.

이어서 서비스를 멈춰 보십시오. **거부되어야 정상입니다.**

```
net stop HanilTimeGuard
```

> `시스템 오류 5이(가) 발생했습니다. 액세스가 거부되었습니다.`
> 이렇게 나오면 제대로 된 것입니다.

서버의 **PC 목록** 화면에서도 그 PC 의 "관리자 권한" 표시가 사라져야 합니다.
(다음 연락 때 반영되므로 1분쯤 걸립니다.)

---

## 이런 것들이 불편해집니다

권한을 낮추면 직원이 못 하게 되는 일들이 있습니다. 미리 알아 두십시오.

| 못 하게 되는 일 | 어떻게 할까 |
|---|---|
| 프로그램 설치 | 관리자가 대신 설치하거나, 설치할 때만 관리자 비밀번호를 입력해 줍니다 |
| 프린터 드라이버 설치 | 관리자가 한 번 설치해 두면 이후엔 그냥 씁니다 |
| 날짜·시간 변경 | 원래 바꾸면 안 되는 것입니다. TimeGuard 는 PC 시간으로 판단하므로 오히려 잘된 일입니다 |
| 일부 오래된 업무 프로그램이 오류 | 아래 참고 |

### 오래된 프로그램이 오류를 낼 때

`C:\Program Files` 안에 자료를 쓰는 옛날 프로그램은 일반 사용자로 실행하면 오류가 납니다.
두 가지 방법이 있습니다.

**방법 1. 그 프로그램 폴더에만 쓰기 권한 주기** (권장)

관리자 권한 명령 프롬프트에서:

```
icacls "C:\Program Files\그프로그램폴더" /grant Users:(OI)(CI)M
```

**방법 2. 관리자 권한으로 실행하게 하기**

프로그램 바로가기 → 오른쪽 클릭 → 속성 → 호환성 → **[관리자 권한으로 이 프로그램 실행]**
→ 실행할 때마다 관리자 비밀번호를 물어봅니다.

> 방법 1 을 권합니다. 방법 2 는 직원이 관리자 비밀번호를 알아야 해서
> 권한을 낮춘 의미가 줄어듭니다.

---

## 여러 대를 한 번에

PC 가 많으면 아래 내용을 메모장에 붙여 넣고 `권한낮추기.bat` 로 저장한 뒤,
각 PC 에서 **관리자 권한으로** 실행하십시오.

```bat
@echo off
chcp 65001 > nul
echo ====================================
echo   직원 계정 권한 낮추기
echo ====================================
echo.

set /p ADMINNAME=관리자로 쓸 계정 이름:
set /p ADMINPW=관리자 계정 비밀번호:
set /p USERNAME_TO_DEMOTE=권한을 낮출 직원 계정 이름:

echo.
echo [1/3] 관리자 계정을 확인합니다...
net user %ADMINNAME% > nul 2>&1
if errorlevel 1 (
    echo   없는 계정이라 새로 만듭니다.
    net user %ADMINNAME% %ADMINPW% /add
    net localgroup Administrators %ADMINNAME% /add
) else (
    echo   이미 있습니다.
    net localgroup Administrators %ADMINNAME% /add > nul 2>&1
)

echo.
echo [2/3] 직원 계정 권한을 낮춥니다...
net localgroup Administrators %USERNAME_TO_DEMOTE% /delete

echo.
echo [3/3] 결과를 확인합니다...
echo.
echo 현재 관리자 권한을 가진 계정:
net localgroup Administrators

echo.
echo 위 목록에 %USERNAME_TO_DEMOTE% 가 없으면 성공입니다.
echo %ADMINNAME% 계정으로 로그인이 되는지 꼭 확인하십시오.
pause
```

> **주의**: 이 방식은 비밀번호가 화면에 보입니다.
> 사람이 없는 곳에서 실행하고, 끝나면 이 파일을 지우십시오.

---

## 도메인을 쓰는 회사라면

사내에 Active Directory 도메인이 있다면, PC 마다 하는 대신
**그룹 정책(GPO)** 으로 한 번에 처리하는 편이 낫습니다.

`컴퓨터 구성` → `정책` → `Windows 설정` → `보안 설정` → `제한된 그룹`
에서 `Administrators` 그룹의 구성원을 지정하면, 도메인에 속한 PC 전체에 적용됩니다.

이 작업은 도메인 관리자가 해야 합니다. 잘 모르시면 전산 담당자나
도메인을 설치해 준 업체에 이 문단을 보여 주십시오.

---

## 되돌리기

문제가 생겨 원래대로 돌려야 한다면, 관리자 계정으로 로그인해서:

```
net localgroup Administrators 직원계정이름 /add
```

---

## 만약 잠겨 버렸다면

관리자 계정으로 로그인할 방법이 전혀 없게 된 경우입니다.
2단계를 건너뛰었을 때 생깁니다.

1. PC 를 켜면서 **Shift 키를 누른 채 [다시 시작]** 을 눌러 복구 화면으로 들어갑니다
2. **문제 해결** → **고급 옵션** → **명령 프롬프트**
3. 여기서 계정을 다시 관리자로 올립니다

이 과정이 어려우시면 전산 담당자나 PC 구입처에 문의하십시오.
**이런 일을 피하려고 2단계에서 반드시 확인하라고 적어 둔 것입니다.**

---

## 정리

1. 서버 **PC 목록**에서 "관리자 권한" 표시된 PC 를 찾는다
2. 그 PC 에 **관리자 계정을 만들고 로그인되는지 확인한다** ← 가장 중요
3. 직원 계정을 일반 사용자로 낮춘다
4. `net stop HanilTimeGuard` 가 거부되는지 확인한다
5. 서버 화면에서 표시가 사라졌는지 본다

이 작업을 마치면 TimeGuard 의 보호가 제대로 동작합니다.
