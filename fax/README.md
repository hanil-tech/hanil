# 📠 받은 팩스 — CimFAX → 한일 포털

CimFAX 팩스 서버로 들어온 팩스를 포털에 자동으로 올리고, 포털의 `/fax` 화면에서 보고 처리하게 하는 포털 조각입니다.

```
CimFAX 장비 → FaxBox(자동 내보내기, PDF) → 공유 폴더 → 포털 fax-route.js (15초마다) → /fax 화면 · 알림
```

- 연동 방법을 고른 근거: [`docs/CimFAX_포털연동_분석.md`](../docs/CimFAX_포털연동_분석.md)의 5.1.1 항목. FaxBox 5022E 를 디컴파일해서 자동 내보내기가 실제로 동작하는 것을 확인했습니다.
- 장비와 직접 통신하는 방식(분석서 6장)은 현장 통신 기록으로 확정한 뒤에 넣을 예정입니다. 그때도 `/fax` 화면과 API 는 그대로 쓰고, 팩스를 가져오는 부분만 바꿉니다.

| 파일 | 내용 |
|---|---|
| `portal/fax-route.js` | 포털에 넣는 조각. 폴더 감시, 저장, API, 화면 연결 |
| `portal/fax-page.html` | `/fax` 화면. PC 와 폰 모두 지원 |
| `portal/설치안내.txt` | FaxBox 설정 → 포털에 넣기 → 확인 순서 |
| `test/` | 가짜 포털과 가짜 내보내기 폴더로 하는 점검 (`npm install && npm test`) |

## 동작
- 새 파일은 **두 번 연속 크기·시각이 같고 5초 넘게 바뀌지 않은 것**만 등록합니다. FaxBox 가 아직 쓰고 있는 파일은 건너뜁니다.
- 파일 이름 `YYYYMMDDhhmmss_From_보낸번호_To_받은계정` 에서 시각, 보낸 번호, 받은 계정을 읽습니다. 하위 폴더 이름은 보낸 곳 이름으로 씁니다.
- 내용이 같은 파일이 두 번 들어오면 하나로 칩니다 (SHA-256 기준).
- 상태: 안 봄 → 확인(PDF 를 열면 자동으로 바뀜) → 처리 완료. 담당자, 메모, 누가 언제 무엇을 했는지 기록이 남습니다.
- 저장은 `fax-store/faxes.json` 에 바꿔치기 방식으로 합니다 (달력 조각과 같은 방식).
