📠 한일 포털 「팩스」 — 설치 안내
=========================================

CimFAX 팩스 서버로 들어온 팩스를 포털에 자동으로 올리고(1·2단계), 포털에서 팩스를 보내게(3단계) 하는 포털 조각입니다.

  받기:  CimFAX 장비 ──▶ 팩스 프로그램(FaxBox)이 받아서 PDF 로 자동 저장 ──▶ 공유 폴더 ──▶ 포털이 15초마다 가져감 ──▶ /fax
  보내기: /fax 「✉ 팩스 보내기」 ──▶ 포털이 PDF 를 팩스 그림으로 바꿈 ──▶ CimFAX 장비에 직접 넘김 ──▶ 전화선


■ 1단계 — 팩스 프로그램(FaxBox) 자동 내보내기 켜기  (팩스를 받는 PC 한 대)

  ① 항상 켜 두는 PC 한 대에서 FaxBox 를 로그인해 둡니다. (Windows 시작 프로그램에 넣기)
  ② 그 PC 에 공유 폴더를 하나 만듭니다.  예) D:\fax-export  → 공유 이름 fax-export
     포털 서버를 돌리는 Windows 계정에 「읽기/쓰기」 권한을 줍니다.
  ③ FaxBox → 설정 → 「Fax automatic export settings」(팩스 자동 내보내기)
       · 자동 내보내기: 켬
       · 폴더: D:\fax-export
       · 형식: PDF    ← 꼭 PDF (TIF 로 두면 포털에서 바로 못 보고 내려받아야 합니다)
       · 하위 폴더: 「보낸 곳별」 권장 (연락처에 거래처 이름이 있으면 그 이름으로 폴더가 생기고, 포털에 이름이 보입니다)
  ④ 테스트 팩스를 한 장 받아 D:\fax-export 에 PDF 가 생기는지 확인합니다.
     파일 이름은  20261112093015_From_0212345678_To_hanil.pdf  같은 모양입니다.


■ 2단계 — 포털에 넣기

  ① 이 압축 파일 안의 두 파일을 포털 폴더(server.js 가 있는 곳)에 복사합니다.
       fax-route.js
       fax-page.html

  ② server.js 를 열어 세션(express-session)이 붙은 줄 아래, 다른 require('./...')(app) 들 사이에 한 줄을 넣습니다.

       require('./fax-route')(app, { inbox: '\\\\FAXPC\\fax-export' });

     (FAXPC 는 1단계 PC 의 이름. 포털과 같은 PC 라면  inbox: 'D:/fax-export'  처럼 써도 됩니다)

  ③ 포털을 다시 켭니다. 끝입니다.
     · 화면:  http://<포털 주소>/fax    — 메뉴에 이 주소로 링크를 달면 됩니다.
     · 메뉴 빨간 숫자:  GET /api/fax/count  →  { new: 안 본 팩스 수 }
     · 자료는 포털 폴더 옆 fax-store\ 에 쌓입니다(백업 대상에 넣어 주세요).
         faxes.json       팩스 목록 · 상태 · 담당자 · 메모 · 기록
         files\*.pdf      팩스 파일


■ 잘 되는지 보기 (관리자)

  브라우저로 포털에 관리자로 로그인한 뒤  http://<포털 주소>/api/fax/admin/status
    inboxes[0].ok 가 true 면 폴더를 읽고 있습니다.
    false 면 error 에 이유가 나옵니다 — 「폴더가 없습니다」 / 「읽을 권한이 없습니다」


■ 더 쓰기 (모두 골라 쓰기)

  담당자 자동 지정 — 거래처별, 받은 계정별
     require('./fax-route')(app, {
       inbox: '\\\\FAXPC\\fax-export',
       route: { from: { '대한상사': 'lee', '0551234567': 'lee' }, to: { public: 'kim' } },
     });

  새 팩스 알림 — 포털 쪽지·NOPS 보내는 함수를 여기에 연결
     require('./fax-route')(app, {
       inbox: '…',
       notify: async (fax, { url }) => { /* 예: sendNops(fax.assignee, '📠 팩스 ' + (fax.from_name || fax.from), url) */ },
     });

  관리자만 보게:            view: 'admin'
  등록한 원본은 옮겨 두기:   after: 'move'     (공유 폴더 안 _포털등록\ 으로 옮김 — 폴더가 깔끔해짐)
  처음 켤 때 옛날 팩스:      sinceDays: 30    (기본 30일치만 가져옴, 0 이면 전부)
  여러 폴더:                 inbox: ['\\\\FAXPC\\fax-export', 'D:/fax2']


■ 3단계 — 포털에서 팩스 보내기 (선택)

  포털이 CimFAX 장비에 직접 접속해서 보냅니다 (FaxBox 를 거치지 않음).
  PDF 를 올리면 포털 서버가 팩스용 흑백 TIFF 로 바꿔 장비로 넘기고, 장비가 전화선으로 보냅니다.

  ① 포털 서버에 Ghostscript 설치 (PDF → 팩스 그림 변환, 무료)
       https://ghostscript.com/releases/gsdnld.html  →  「Ghostscript AGPL Release」 Windows 64bit 받아 설치
       (기본 위치 C:\Program Files\gs\… 에 깔면 포털이 알아서 찾습니다)

  ② 포털 폴더에 두 파일을 더 복사합니다.
       cimfax-client.js     장비와 통신
       cimfax-check.js      장비 점검 도구

  ③ 먼저 장비와 말이 통하는지 확인 (포털 서버의 명령 프롬프트, 포털 폴더에서)

       node cimfax-check.js --host 192.168.0.50 --user CimFAX계정 --pass 비밀번호

     「✅ 로그인 성공」 이 나오면 됩니다.  (192.168.0.50 = CimFAX 장비 주소. FaxBox 로그인 화면에 보이는 주소)
     ⚠ 포털 전용 CimFAX 계정을 하나 만들어 쓰는 것을 권합니다 (FaxBox → 서버 → 사용자 계정 → 추가, 「보내기」 권한).

  ④ 시험 팩스 한 장 — 우리 회사 팩스 번호나 아는 번호로

       node cimfax-check.js --host 192.168.0.50 --user CimFAX계정 --pass 비밀번호 --send 0212345678 --file 시험.pdf

     「✅ 장비가 받았습니다 — 작업번호 N」 → 실제로 팩스가 나갔는지, 받은 쪽 종이가 깨끗한지 확인합니다.
     FaxBox 의 「보낸 팩스」 목록에도 보여야 합니다.

  ⑤ server.js 의 한 줄에 device 를 더합니다.

       require('./fax-route')(app, {
         inbox: '\\\\FAXPC\\fax-export',
         device: { host: '192.168.0.50', user: 'CimFAX계정', password: '비밀번호' },
       });

     비밀번호를 server.js 에 적기 싫으면 환경 변수로:  FAX_DEVICE_HOST · FAX_DEVICE_USER · FAX_DEVICE_PASSWORD
     처음 며칠은  device: { …, dryRun: true }  로 켜 두면 변환까지만 하고 장비로는 안 보냅니다(화면 연습용).

  ⑥ 포털을 다시 켜면 /fax 화면 오른쪽 위에 「✉ 팩스 보내기」 버튼과 「보낸 팩스」 칸이 생깁니다.
     · 받는 번호는 쉼표로 여러 곳(20곳까지) — 번호마다 따로 보냅니다
     · 상태: 대기 → 변환 중 → 장비로 보내는 중 → 장비 접수(작업번호) — 실패하면 이유와 「다시 보내기」
     · 접수된 뒤에는 1분마다 장비에 물어서 「보낸 쪽 n/m · 다이얼 횟수」 를 보여 줍니다

  보내기 권한:   sendBy: 'admin'  (관리자만) 또는  sendBy: (u) => ['kim','lee'].includes(u.id)
  보낸 목록:     기본은 자기가 보낸 것만 — 모두 보게 하려면  sentView: 'all'   (관리자는 언제나 전부)


■ 문제가 생기면

  · 팩스가 안 올라온다
      1) 공유 폴더에 PDF 가 생겼는지 → 안 생기면 FaxBox 쪽(켜져 있는지, 자동 내보내기 설정)
      2) /api/fax/admin/status 의 오류 → 권한·경로
  · 보내기 「Ghostscript 가 없습니다」 → ① 설치, 또는 device 에  ghostscript: 'C:/Program Files/gs/gs10.04.0/bin/gswin64c.exe'
  · 보내기 「CimFAX 계정 또는 비밀번호가 틀립니다」 → FaxBox 로 같은 계정 로그인이 되는지 확인
  · 보내기 「…3002 접속 실패」 → 포털 서버에서 장비 주소로 ping, 방화벽(TCP 3001~3007)
  · 포털 화면에서 「브라우저에서 바로 볼 수 없습니다」 → FaxBox 내보내기 형식이 TIF 입니다. PDF 로 바꿔 주세요.
    (PDF 변환에 실패한 팩스는 FaxBox 가 …_PdfErr.tif 로 남깁니다 — 이것도 포털에 올라오고 내려받아 볼 수 있습니다)
