📠 한일 포털 — CimFAX 수신팩스 연동 설치 안내
=====================================================

받은 팩스를 포털 「팩스함」에서 보고, 거래처·담당자에 자동으로 이어 주는 포털 조각입니다.
사내 PC 의 수집 에이전트(fax-agent)가 FaxBox 에서 내보낸 PDF 를 포털에 올리면, 포털이
PDF 보관 · 쪽수/썸네일 · 거래처 자동매칭 · 담당자 배정 · 알림을 합니다.
(설계서 「CimFAX 수신팩스 포털 연동」 4·5·7장 기준)

이 폴더의 파일
    fax-route.js     포털에 넣는 길(엔드포인트)
    fax-page.html    팩스함 화면
    fax-schema.sql   DB 표 5개 (MSSQL)
    README.md        같은 내용 짧게 + 엔드포인트 목록

─────────────────────────────────────────────────────
1. DB 표 만들기
─────────────────────────────────────────────────────
  fax-schema.sql 을 포털 DB(MSSQL)에 한 번 돌립니다. 표 5개가 생깁니다:
    fax_inbox (받은 팩스) · fax_sender_map (번호→거래처 학습) · fax_link (팩스↔전표)
    fax_event (열람·배정 기록) · fax_agent_status (에이전트 보고)
  ⚠ 포털 DB 가 MySQL 이면 파일 맨 위 주석의 타입 바꾸기 표를 따르고, 2번 ctx 에 dialect:'mysql' 을 넣으세요.

─────────────────────────────────────────────────────
2. 포털에 길 붙이기 (server.js)
─────────────────────────────────────────────────────
  fax-route.js · fax-page.html 을 포털 폴더(server.js 옆)에 둡니다.
  server.js 에서 세션(express-session)이 붙은 줄 아래, 다른 require('./...')(app) 들 사이에:

      require('./fax-route')(app, {
        db: faxDb,                               // ← DB 실행기 (아래 ★)
        agentToken: process.env.FAX_AGENT_TOKEN, // ← 에이전트 토큰 (아래 3번)
        // dialect: 'mysql',                     // MySQL 이면
        // matchPartner: faxMatchPartner,        // 거래처 자동매칭 (아래 4번) — 없으면 학습표만
        // assigneeOf: (pid) => 거래처담당자번호,  // 담당자 자동배정 — 없으면 배정 안 함
        // notify: (kind, info) => { ... },       // 알림 — 없으면 조용
      });

  ★ db 는 async (sql, params) => rows 입니다. sql 의 자리표시는 '?'(차례대로).
    포털이 쓰는 mssql 패키지(pool)로 감싸는 예(?→@p 로 바꿔 줍니다):

      const sql = require('mssql');
      async function faxDb(q, params) {
        const rq = pool.request();
        let i = 0;
        const text = q.replace(/\?/g, () => { const n = 'p' + (i); rq.input(n, params[i++]); return '@' + n; });
        const r = await rq.query(text);
        return r.recordset || [];
      }

    (MySQL 이면 mysql2 의 pool.query(q, params) 결과의 첫 배열을 그대로 돌려주면 됩니다.)

  포털 메뉴에 「팩스함」을 /fax 주소로 달아 주세요. 로그인해야 열립니다.
  받은 팩스 파일은 포털 폴더 옆 fax-store\ 에 쌓입니다(백업 대상에 넣어 주세요).
    · 다른 곳에 두려면 ctx 에  dir: 'D:/portal-data/fax'

─────────────────────────────────────────────────────
3. 에이전트 토큰 (사내 PC ↔ 포털)
─────────────────────────────────────────────────────
  수집 에이전트만 팩스를 올릴 수 있게 하는 비밀 열쇠입니다. 업로드·보고 전용이고,
  사내망 IP 에서만 받습니다(설계서 보안). 아무도 모르는 긴 값으로 만드세요:

      node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"

  ① 포털 서버의 환경변수  FAX_AGENT_TOKEN  에 그 값을 넣고 포털을 다시 켭니다.
  ② 팩스 PC(에이전트)에도 같은 값을 시스템 환경변수  FAX_AGENT_TOKEN  에 넣습니다.
     그리고 fax-agent 의  -ApiBase  를 포털 주소로 맞춥니다. 예:
        -ApiBase http://192.168.1.30:8820   (사내)  또는  https://work.hanil-steel.com
  ⚠ 토큰은 스크립트에 쓰지 말고 환경변수로만. 가끔 바꿔 주세요(양쪽 같이).

─────────────────────────────────────────────────────
4. 거래처 자동매칭 (설계서 5.2)
─────────────────────────────────────────────────────
  순서: ① 보낸번호 숫자만 → ② 학습표(fax_sender_map) → ③ 거래처 팩스/전화 완전일치
        → ④ 뒤 8자리 같은 거래처 '후보' 제안(자동 확정 안 함)
  인터넷팩스 이름(SmartWorks·ACEFAX·KODIT EFAX·SENDLABS FAX1/2)·의미없는 번호는 미매칭.

  ②(학습표)는 이 조각이 알아서 합니다. ③④(거래처표 대조)는 거래처 표를 알아야 하므로
  포털이 ctx.matchPartner 로 알려 주세요(숫자만 번호를 받아 거래처를 찾는 함수). 예:

      async function faxMatchPartner(digits) {
        // 완전일치 (거래처 팩스/전화/전화2 의 숫자만과 비교)
        const ex = await faxDb(
          "SELECT TOP 1 id FROM 거래처 WHERE replace(replace(fax,'-',''),' ','')=? " +
          "OR replace(replace(tel,'-',''),' ','')=?", [digits, digits]);
        if (ex[0]) return { partner_id: ex[0].id, match_type: 'exact' };
        // 뒤 8자리 후보
        const last8 = digits.slice(-8);
        const sg = await faxDb("SELECT TOP 5 id, name FROM 거래처 WHERE fax LIKE ? OR tel LIKE ?", ['%'+last8, '%'+last8]);
        return sg.length ? { suggest: sg.map(r => ({ id: r.id, name: r.name })) } : null;
      }

  ※ 거래처 표·칸 이름은 포털(경영박사 이관)에 맞춰 고치세요. 안 넘기면 학습표만으로 돕니다.
  ※ 손으로 거래처를 바꾸면 그 번호가 학습표에 저장돼 다음부터 자동입니다.

─────────────────────────────────────────────────────
5. TIF→PDF · 쪽수 · 썸네일 (서버 도구, 권장)
─────────────────────────────────────────────────────
  포털 서버에 아래가 있으면 TIF 를 PDF 로 바꾸고 쪽수·첫 장 썸네일을 만듭니다(없어도 돕니다 — 원본만 보관):
      우분투:  sudo apt-get install -y imagemagick poppler-utils ghostscript
      윈도우:  ImageMagick + poppler(pdfinfo·pdftoppm) 설치 후 PATH 에
  ⚠ ImageMagick 의 PDF 정책(policy.xml)이 막혀 있으면 PDF 썸네일이 안 됩니다 → poppler(pdftoppm)가 있으면 그걸 씁니다.

─────────────────────────────────────────────────────
6. 엔드포인트 (요약)
─────────────────────────────────────────────────────
  에이전트(토큰):
    POST /api/fax/inbound        받은 팩스 올리기 (multipart) → 신규 201 / 중복 409
    POST /api/fax/agent-report   5분마다 점검 보고(FaxBox 실행·누락 목록) → 200
  사람(로그인):
    GET   /api/fax               목록·검색   GET /api/fax/{id}   상세
    GET   /api/fax/{id}/file     PDF (로그인만·공유 불가)   /thumb  썸네일
    PATCH /api/fax/{id}          거래처·분류·담당자·상태·메모
    POST  /api/fax/{id}/links    전표 연결      GET /api/fax/stats   통계
    GET   /api/fax/agent-status  에이전트 상태(관리자)
    GET   /fax                   팩스함 화면

─────────────────────────────────────────────────────
7. 보안·보관 (설계서 5.5)
─────────────────────────────────────────────────────
  · 팩스에는 주민번호·계좌·계약서가 있을 수 있습니다 → 파일은 로그인 다운로드로만 내줍니다(공개 주소 없음).
  · 열람·배정·상태변경은 fax_event 에 남습니다.
  · 보관 기간(예: 5년)은 세무사와 확인해 정하세요. 오래된 것 지우기는 아직 자동이 아닙니다(필요하면 추가).
  · 누락(미저장)·에이전트 끊김(15분)·누락 1시간 초과는 팩스함 위에 경고로 뜨고, notify 를 넘기면 관리자 알림도 보냅니다.
