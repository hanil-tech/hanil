# 포털에 넣을 것 — 직원 국적별 인원 (라벨 발행기 v1.7.0~)

라벨 발행기의 언어 고르기 화면이 **우리 직원들 국적의 말만** 보이게 하려면
포털 `labels.js` 에 읽기 전용 주소 하나가 필요합니다.

    GET /api/labels/staff-langs   (라벨 권한)
    → { ok: true, nats: [ { nat: "베트남", n: 12 }, { nat: "", n: 30 }, ... ] }

- **이름·사번·연락처는 주지 않습니다.** 국적 글자와 인원 수뿐입니다.
- 재직자만 셉니다(사용 안 함·퇴사자 제외). 국적이 빈 사람은 한국인으로 봅니다.

## 넣는 법

포털 폴더(`server.js` 가 있는 곳)에서:

    patch -p1 < labels-staff-langs.patch

또는 `labels.js` 에서 `app.post('/api/labels/form-names'` 줄 바로 위에
패치 파일의 `+` 줄들을 붙여 넣고 포털을 다시 켭니다.

## 넣기 전에는

라벨 발행기는 이 주소가 없으면(404) **12개 말을 모두** 보입니다 — 지금과 같습니다.
