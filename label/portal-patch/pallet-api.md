# 포털에 넣을 것 — 파레트 라벨을 샘플로 (라벨 발행기 v2.4.0~)

현장 키오스크 옆에 **파레트 라벨(QR `HANIL-PL|P00011`)** 을 샘플로 붙여 두고 리더기로 찍으면,
라벨 발행기가 포털에 그 파레트에 담긴 품번·수량을 물어 **같은 묶음으로 새 파레트 라벨**을 뽑습니다.
포털 `labels.js` 에 읽기 전용 주소 하나가 필요합니다.

## 주소

    GET /api/labels/pallet/P00011      (라벨 권한 · apiAuth)

### 찾았을 때 — 200

```json
{ "ok": true,
  "pallet": {
    "no": "P00011",
    "form": "양식 값 (라벨 화면 #form 의 option value 와 같은 글자)",
    "sheet": "라벨지 값 (라벨 화면 SHEETS[].key 와 같은 글자)",
    "copies": 1,
    "items": [
      { "part_no": "7416432-WD", "part_name": "브라켓", "customer": "현대", "model": "", "spec": "",
        "unit": "EA", "qty": 50, "img_id": 0 },
      { "part_no": "7416433-WD", "part_name": "커버", "customer": "현대", "qty": 30 }
    ] } }
```

- `items` 는 그 파레트 라벨을 **처음 뽑을 때 담았던 줄 그대로**(품번·수량). 순서도 그대로.
- `form` · `sheet` · `copies` 는 모르면 빼도 됩니다(키오스크가 지난번 고른 것을 씁니다).
- 대소문자: 키오스크는 번호를 **대문자로** 보냅니다(`p00011` → `P00011`).

### 없는 번호 — 404 + `code`

```json
{ "ok": false, "code": "NO_PALLET", "error": "없는 파레트 번호입니다 (P00099)" }
```

⚠ **`code` 칸을 꼭 넣어 주세요.** 키오스크는 404 에 `code` 가 없으면
«포털에 이 주소가 아직 없다»로 보고 예전 안내(「상세 화면에서 뽑아 주세요」)를 띄웁니다.

### 내려 둔 샘플 — 410 (선택)

```json
{ "ok": false, "code": "RETIRED", "error": "내려 둔 파레트 샘플입니다(P00011) — 이 종이는 떼어 주세요" }
```

`error` 글이 키오스크 화면에 빨갛게 그대로 나옵니다.

## 지킬 것

- **읽기만** 합니다. 새 파레트 번호·로트·고유번호는 키오스크가 다시 뽑을 때 `/api/labels/make` 가 늘 하던 대로 매깁니다.
  (샘플 종이의 P00011 을 다시 쓰면 안 됩니다 — 출고 때 같은 번호 두 장이 됩니다.)
- 라벨 발행기의 관문은 `/api/labels/` 아래 **GET** 을 이미 통과시킵니다 — 관문은 고칠 것 없습니다.
- 품번 하나짜리 견본(`/api/labels/sample/:번호`)과 같은 모양으로 두면 됩니다.

## 키오스크가 하는 일 (참고)

1. `HANIL-PL|P00011` 을 읽는다(한글 자판 `ㅗ무ㅑㅣ-ㅔㅣ|ㅔ00011` 도 같다).
2. 위 주소로 묻는다 → 품번 목록과 수량 칸을 보인다(수량은 고칠 수 있다).
3. 「라벨 발행」 → 숨은 라벨 화면(`/kiosk/label`)에
   `CART` = 담긴 품번들(각 `n:1`), `#bundleChk` 켜기, 「몇 장 (한 라벨로 묶을 때)」 칸 = 장수,
   양식·라벨지를 넣고 `preview()` → `printHere()`. 끝나면 `#bundleChk` 를 다시 끈다.

⚠ 라벨 화면에서 묶기를 켜면 `CART` 를 다시 그리거나 지우는 코드가 있다면, 키오스크는 켠 뒤에 `CART` 를 한 번 더 넣습니다.
「몇 장」 칸은 이름(id)을 몰라 글자(`몇 장` + `묶`)로 찾습니다 — 그 칸에 `id="bundleCopies"` 같은 이름을 붙여 주시면 알려 주세요, 그 이름으로 바꾸겠습니다.

# 👁 미리보기 주소 (라벨 발행기 v2.5.0~)

키오스크의 파레트 화면 왼쪽 아래에 **라벨 미리보기**가 나옵니다. 그런데 라벨 화면의 `preview()` 는
그리는 순간 `POST /api/labels/make` 로 **번호·로트를 매기고 남깁니다** — 미리보기만 할 때 부르면 뽑지도 않은 라벨이 쌓입니다.
그래서 키오스크는 미리보기 동안 그 요청을 **같은 몸통 그대로** 아래 주소로 돌립니다.

    POST /api/labels/make-preview      (라벨 권한 · apiAuth · json())

- 몸통(body)은 `/api/labels/make` 와 **똑같습니다**. 답도 **똑같은 모양**으로 주세요 — 라벨 화면이 그 답으로 그림을 그립니다.
- ⚠ **DB 에 아무것도 쓰지 않습니다.** 로트 차례·고유번호 차례·파레트 번호 차례도 올리지 않습니다.
  번호 칸에는 `미리보기` 나 `P?????` 같은 자리 글자를 넣어 주세요(QR 도 그 글자로 그려지면 됩니다).
- 가장 쉬운 방법: make 의 «번호 매기기 + 그리기 + 저장» 중 **저장만 빼고**, 번호는 `peek`(다음 번호를 보기만)하거나 자리 글자로.
- 키오스크 관문(v2.5.0~)은 이 주소를 이미 통과시킵니다.
- 이 주소가 없으면(404) 키오스크는 「미리보기는 포털 업데이트 뒤에 보입니다」만 띄웁니다 — **진짜 make 로 새지 않습니다.**
