# 한일 라벨 발행기 (`hanil-label.exe`)

현장 키오스크에서 **라벨만** 뽑는 Windows 프로그램입니다.
작업이 끝나면 바코드 리더기로 품번을 찍고, 담고, 인쇄합니다.
바코드(라벨) 프린터와 레이저 프린터(A4 라벨지)를 모두 쓸 수 있습니다.

**[⬇ hanil-label.exe 내려받기](https://github.com/hanil-tech/hanil/raw/HEAD/release/hanil-label-v2.1.0.exe)** (약 6MB, 설치 없음)

## 쓰는 법 (간편 발행 화면)

0. 켜면 **언어 고르기** 화면이 먼저 나옵니다 — 한국어·English·Tiếng Việt·မြန်မာ·ไทย·Русский·中文.
   (v1.6.0 부터 O‘zbekcha·नेपाली·ខ្មែរ·Bahasa Indonesia·සිංහල 도 — 포털 인사카드 국적 기준. 필리핀은 English, 키르기스·카자흐는 Русский)
   고른 말로 메뉴가 나옵니다(라벨에 찍히는 글자는 그대로 한국어).
   v1.7.0 — 포털에 [국적별 인원 주소](portal-patch/README.md)를 넣으면 **우리 직원들 국적의 말만**(인원 많은 순) 보입니다. 3분 동안 아무도 안 쓰면 다음 사람을 위해 다시 이 화면으로 돌아갑니다.
   찾기 화면 아래 국기나 오른쪽 위 언어 단추로 언제든 바꿀 수 있고, 언어 화면에서 바로 리더기로 찍어도 됩니다.
   왼쪽 위 **🏠 처음으로** 를 누르면 언제든 첫 찾기 화면으로 돌아갑니다.
   오른쪽 위 **「상세 화면」**(포털 라벨 화면)도 고른 말로 바뀌고, 왼쪽 아래 🏠 단추로 돌아옵니다.

1. 가운데 검색창에 **품번·품명**을 두세 글자 치면 **바로 아래에 사진과 함께 후보**가 뜹니다(↑↓ 로 고르고 Enter, 또는 누르기).
   Enter 만 누르면 찾은 품목 전체가 사진 카드로 나옵니다.
2. 품목을 누르면 **큰 사진**과 함께 수량 칸이 뜹니다 → **수량** 넣고 Enter(또는 「🏷 라벨 발행」).
3. 발행하면 첫 화면으로 돌아가 다음 품번을 기다립니다.

**라벨 샘플 찍기** — 품번마다 라벨을 한 장씩 키오스크 옆에 붙여 두고, 리더기로 그 QR 을 찍으면
그 품번이 바로 열리고 수량 칸에 샘플의 수량이 들어가 있습니다. 수량만 확인하고 Enter.
- 키보드가 **한글 상태**여도 됩니다(리더기 글자가 한글로 들어와도 영문으로 되돌려 읽습니다).
- 그 품번을 지난번에 뽑은 **라벨지·양식**을 기억해 두었다가 그대로 씁니다.
- 파레트 라벨(여러 품번 묶음)·줄 나누기 같은 일은 오른쪽 위 **「상세 화면」**에서 합니다.

## 독자 창 (v2.0.0~)

Edge 창을 빌려 쓰지 않고 **이 프로그램의 창**으로 뜹니다 — 제목줄·아이콘·작업 표시줄이 모두 「한일 라벨 발행」.
창 안은 윈도우 10·11 에 들어 있는 WebView2(Edge 엔진)가 그리고, 라벨은 예전처럼 포털 것을 그대로 씁니다.
- 창을 닫으면 프로그램도 끝납니다. 바탕화면 아이콘을 또 누르면 떠 있는 창이 앞으로 옵니다.
- WebView2 가 없는 오래된 PC 에서는 예전처럼 Edge 창으로 뜹니다.
- 로그인·언어 설정은 `%LOCALAPPDATA%\HanilLabel\WebView2` 에 남습니다(처음 한 번은 다시 로그인).

## 어떻게 동작하나

```
 키오스크 PC                                   회사 서버
┌──────────────────────────────────┐        ┌───────────────────┐
│ hanil-label.exe                  │        │ 한일 포털          │
│  ├ 관문 127.0.0.1:18830 ─────────┼──────▶ │  /kiosk/label     │
│  │  라벨 길만 통과                │        │  /api/labels/...  │
│  └ Edge 앱 창 (주소창 없음)       │        └───────────────────┘
│       └ 🖨 바코드 / 레이저 프린터 │
└──────────────────────────────────┘
```

- 라벨 화면은 **포털의 키오스크 라벨 화면(`/kiosk/label`)을 그대로** 씁니다.
  로트·고유번호·QR 을 포털이 매기므로 사무실에서 뽑은 라벨과 번호가 이어지고,
  사무실 라벨 화면(`/labels`)에서 맞춘 여백·양식도 그대로 따라옵니다.
- 프로그램 안의 **관문**은 라벨 화면과 로그인에 필요한 길만 통과시킵니다.
  어떤 계정으로 로그인하든 이 창에서는 급여·회계 같은 다른 메뉴가 열리지 않습니다.
  양식 이름 바꾸기·미세조정 저장 같은 **설정 변경도 막혀 있습니다**(사무실에서만).
- 로그인하면 포털 첫 화면이 아니라 **곧장 라벨 화면**이 열립니다.
- 사내 주소(`192.168.1.30:8820`)를 먼저 붙어 보고, 안 되면 도메인으로 붙습니다.
- 서버가 꺼지거나 선이 빠지면 안내 화면이 뜨고, 30초마다 저절로 다시 붙어 봅니다.

## 새 판으로 바꾸기

받은 `hanil-label.exe` 를 **어디에 두었든 한 번 두 번 누르면** 됩니다(바탕화면 아이콘 말고 받은 파일을 직접).
- 새 판이면 `%LOCALAPPDATA%\HanilLabel\app\` 에 스스로 설치해 예전 판을 바꾸고,
  바탕화면·시작 메뉴 아이콘도 그 자리로 고칩니다. 설정 파일(`hanil-label.ini`)도 옮겨 옵니다.
- 그 뒤로는 바탕화면 아이콘만 누르면 늘 새 판이 뜹니다. 받은 파일은 지워도 됩니다.
- 화면 오른쪽 아래에 판 번호(예: `v1.4.0`)가 보입니다.

## 설치 (키오스크 한 대당 2분)

1. `hanil-label.exe` 를 키오스크 PC 의 아무 폴더에 둡니다(예: `C:\한일\`).
2. 두 번 눌러 실행합니다. 옆에 `hanil-label.ini` 설정 파일이 저절로 생깁니다.
3. 처음 한 번 **「이 키오스크의 계정」** 화면에 현장용 계정(라벨 권한, 2단계 인증 없음)을 넣습니다.
   그 뒤로는 **로그인 화면이 없습니다** — 프로그램이 포털에 저절로 로그인하고, 끊기면 다시 로그인합니다.
   - 비밀번호는 윈도우 DPAPI 로 이 PC 에서만 풀리게 암호화해 `%LOCALAPPDATA%\HanilLabel\account.dat` 에 둡니다.
   - 여러 대를 한꺼번에 깔 때는 `hanil-label.ini` 에 `USER=` · `PASSWORD=` 를 적어 두면 처음 켤 때 암호화해 옮기고 `PASSWORD` 는 지웁니다.
   - 포털에서 그 계정의 비밀번호를 바꾸면 계정 화면이 다시 나옵니다. 계정을 바꾸려면 `account.dat` 를 지우고 켭니다.
4. 처음 실행하면 **바탕화면과 시작 메뉴에 「한일 라벨 발행기」 아이콘이 저절로 생깁니다.**
   다음부터는 그 아이콘으로 켭니다. exe 를 다른 폴더로 옮겨도 다음 실행 때 아이콘이 새 자리로 고쳐집니다.
   윈도우가 켜질 때 저절로 띄우려면 `hanil-label.ini` 에서 `AUTOSTART=1` 로 바꿉니다.

> **파일이 안 열릴 때** — 파란 화면 "Windows의 PC 보호" → **[추가 정보]** → **[실행]**.
> 사내에서 만든 프로그램이라 서명이 없어서 그렇습니다.

> **계정** — 키오스크 **전용 계정 종류(kiosk)** 가 아니라 **일반 계정**으로 로그인합니다.
> 라벨 메뉴만 쓸 수 있는 현장용 계정을 하나 만들어 두시길 권합니다.
> (포털의 키오스크 계정은 포털 문지기가 라벨 화면을 막고 있어 쓸 수 없습니다 — 아래 «알려 드릴 것» 참고)

## 프린터

`hanil-label.ini` 의 `PRINT` 로 정합니다.

| 설정 | 동작 | 이런 자리에 |
|---|---|---|
| `PRINT=dialog` (기본) | 인쇄 창이 떠서 **바코드 프린터 / 레이저 프린터를 그때그때 고릅니다.** 마지막에 고른 프린터를 기억합니다. | 두 프린터를 같이 쓰는 자리 |
| `PRINT=silent` | 인쇄 창 없이 이 PC 의 **기본 프린터**로 바로 나갑니다. | 라벨 프린터 한 대만 쓰는 자리 |

- **바코드 프린터**: 제조사 Windows 드라이버를 설치하고, 드라이버의 용지 크기를
  라벨 크기(예: 100×100mm)로 맞춘 뒤, 라벨 화면 아래 **용지**에서 `100` 을 고릅니다.
- **레이저 프린터**: A4 라벨지를 넣고 **용지**에서 칸 수(8·10·12칸 등)를 고릅니다.
- `silent` 로 쓸 때는 윈도우 설정 → 프린터 및 스캐너 → 라벨 프린터 → **기본값으로 설정**,
  그리고 **「Windows에서 기본 프린터 관리」는 끕니다**(켜 두면 마지막에 쓴 프린터로 바뀝니다).
- 인쇄 창에서는 **배율 100% · 여백 없음**으로 두세요. 자리가 어긋나면 사무실 `/labels` 화면에서 여백을 맞춥니다.

## 바코드 리더기

리더기는 키보드처럼 글자를 넣고 Enter 를 칩니다. 라벨 화면의 찾기 칸을 누르고 찍으면
바로 찾습니다. 「생산계획에서」「품목에서」 중 찾을 곳을 먼저 고르세요.

## 설정 파일 (`hanil-label.ini`)

```ini
URL=http://192.168.1.30:8820, https://work.hanil-steel.com   ; 앞의 것부터 붙어 봅니다
PRINT=dialog        ; dialog = 인쇄 창에서 프린터 고르기 / silent = 기본 프린터로 바로
FULLSCREEN=0        ; 1 = 화면 전체(키오스크). 끄기는 Alt+F4
SHORTCUT=1          ; 1 = 바탕화면·시작 메뉴 아이콘을 (없으면) 만듭니다
AUTOSTART=0         ; 1 = 윈도우가 켜지면 저절로 띄웁니다
PORT=18830          ; 이 PC 안의 관문 번호(다른 프로그램과 겹칠 때만 바꿉니다)
BROWSER=            ; 비우면 Edge → Chrome 순으로 찾습니다
```

로그인 정보는 이 프로그램만의 자리(`%LOCALAPPDATA%\HanilLabel`)에 따로 보관되어,
직원이 쓰는 Edge 와 섞이지 않습니다. 로그아웃하려면 그 폴더를 지우면 됩니다.

## 게시자 (「Windows의 PC 보호」 창)

받은 exe 를 처음 열 때 «게시자: 알 수 없는 게시자» 파란 창이 뜹니다 → **[추가 정보] → [실행]**.
- 한 번 실행하면 `%LOCALAPPDATA%\HanilLabel\app` 에 설치되고, 그 뒤 바탕화면 아이콘으로 켤 때는 이 창이 안 뜹니다.
- 「게시자」 칸에 **한일특장(주)** 가 나오게 하려면 회사 이름으로 발급받은 **코드 서명 인증서**로 서명해야 합니다
  (exe 안의 글자로는 바꿀 수 없습니다 — 윈도우는 인증서만 믿습니다). 인증서가 생기면 `build.sh` 가 서명까지 합니다.

## 문제가 생기면

- 켤 때마다 이 프로그램이 쓰던 Edge 창·예전 판·창 자리 기억을 치우고 새로 엽니다.
  그래도 안 되면 창을 닫고 `%LOCALAPPDATA%\HanilLabel` 폴더를 지운 뒤 다시 켭니다(로그인은 다시 해야 합니다).
- 기록 파일: `%LOCALAPPDATA%\HanilLabel\hanil-label.log` — 안 될 때 이 파일을 보내 주세요.

## 알려 드릴 것 (포털 쪽)

포털 v12.73.0 소스를 보다가 발견한 것입니다. 이 프로그램은 아래 문제를 비켜 가도록 만들었지만,
포털에서도 고치시면 좋습니다.

1. **키오스크 라벨(`키오스크-라벨.bat`)의 로그인이 막다른 길입니다.**
   `/kiosk/label` 은 로그인이 안 되어 있으면 `/kiosk/login?mode=label` 로 보내는데,
   - 그 로그인 화면은 **키오스크 계정만** 받고, 들어오면 `/kiosk?mode=label` 로 보냅니다
     (라벨 화면이 아니라 `/kiosk` 화면이고, 기기 열쇠가 없는 PC 는 거기서 막힙니다).
   - 그런데 `server.js` 의 `KIOSK_OK` 목록에 `/kiosk/label`·`/api/labels/` 가 없어서
     **키오스크 계정은 라벨 화면에 들어갈 수 없습니다.**
2. 이번에 받은 zip 은 **전체가 아닙니다**(`kst.js`·`db.js` 등 100여 개 모듈이 빠져 있어 서버가 뜨지 않습니다).

## 만들기 (개발자용)

```bash
./label/build.sh      # → release/hanil-label.exe
```

Go 표준 라이브러리만 씁니다. 시험은 리눅스에서 `go build` 후
`--url=http://포털 --browser=/bin/true` 로 관문만 띄워 확인할 수 있습니다.
