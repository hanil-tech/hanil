🔎 한일 포털 — 스캔 서식 OCR (생산일지 등) 설치·사용 안내
=============================================================

손으로 쓴 생산일지·팩스를 Claude(비전)로 읽어 표로 돌려주는 모듈입니다.
지금 포털 「AI 창구」의 인식률이 낮은 까닭을 네 가지로 고쳤습니다.

왜 지금 인식률이 낮았나 → 이 모듈이 고치는 것
---------------------------------------------
 ① 쪽마다 방향이 다름(어떤 장은 90° 돌아가 스캔됨) → 돌아간 장은 OCR이 거의 안 됩니다.
      → 쪽마다 먼저 **똑바로 세웁니다**(싼 모델로 방향만 보고 회전).
 ② 10쪽을 한 번에·전처리 없이 보냄 → 한 장당 해상도가 낮아 흐립니다.
      → **쪽마다 따로**, 고해상도로 그려 **회색·기울기보정·대비·선명화** 후 보냅니다(연필 글씨가 또렷해짐).
 ③ 가장 작은 모델(Haiku 4.5) → 손글씨엔 약합니다.
      → 기본 **Opus 5.5**(강함). 비용을 줄이려면 Sonnet 5.5 로 바꿀 수 있습니다.
 ④ "그냥 읽어" → 칸을 비우거나 지어냅니다.
      → 서식의 **칸 구조 + 아는 품번·공정·설비 목록**을 주어 맞춰 읽게 하고,
        **칸마다 확신도(0~100)**를 받습니다(모르면 비움, 지어내지 않음). 사람이 확신 낮은 칸만 고치면 됩니다.

설치 (포털 서버)
----------------
 1. ocr-read.js 를 포털 폴더에 둡니다.
 2. 서버에 도구 설치(쪽 그림·전처리용):
       우분투:  sudo apt-get install -y poppler-utils imagemagick
 3. SDK 설치:  (포털 폴더에서)  npm i @anthropic-ai/sdk
 4. 환경변수  ANTHROPIC_API_KEY  에 포털이 쓰는 Claude 키를 넣습니다(이미 AI 창구가 쓰고 있을 것).

쓰는 법 (포털 「AI 창구」에서)
-----------------------------
    const { extractProductionLog } = require('./ocr-read');

    const out = await extractProductionLog({
      pdf: '/올라온/생산일지.pdf',          // 또는  images: ['p1.png','p2.png', ...]
      items:     ['405950524-WD', '7416433-WD', ...],   // ERP 의 아는 품번 목록(맞춰 읽음) — 강력 추천
      processes: ['사상','조립','포장','검사'],
      machines:  ['M-1','라인1','UDI'],
      // model: 'claude-sonnet-5-5',        // 비용을 줄이려면(정확도 조금 ↓)
    });
    // out.rows = [{ page, worker_name, date, part_no, process, machine, start, end, qty_good, qty_bad, bad_reason, confidence:{칸:0~100} }, ...]
    // out.pages = [{ page, worker_name, date, confidence, rowCount }, ...]

 · **아는 품번 목록(items)을 꼭 넘겨 주세요.** 손글씨 "405950524-WD" 를 목록의 정확한 품번으로 맞춰 읽어 품번 인식률이 크게 오릅니다.
 · 쪽수 제한이 없습니다(14쪽이면 14쪽 다 읽습니다 — 쪽마다 따로).
 · 확신도가 낮은 칸만 사람이 확인·수정하게 화면에 노랗게 표시하면 됩니다(지금 화면의 「확신 %」 그대로 쓸 수 있음).

CLI 로 시험
-----------
    node ocr-read.js 생산일지.pdf        # 결과 JSON 출력

비용·모델
---------
 · 기본 Opus 5.5 — 손글씨에 가장 정확. 쪽당 비용이 조금 듭니다(이미지 1장 + 짧은 표).
 · 더 싸게:  model:'claude-sonnet-5-5' (절반 값, 정확도 약간 ↓) 또는  OCR_MODEL 환경변수.
 · 방향 보기는 싼 Haiku 로만 합니다(각도 숫자 하나만).

메모
----
 · 생산일지 외 다른 서식도 됩니다:  extractForm({ pdf, columns:[{key,desc},...], items, ... }) 로 칸을 바꿔 주세요.
 · 읽은 값은 **사람 확인 뒤 저장**(지금 화면처럼) — OCR 은 사람을 돕는 것이지 대신하지 않습니다.
 · 전처리(회색·기울기·대비·선명)만으로도 돌아간 장·흐린 장이 크게 좋아집니다. 샘플: 돌아가 있던 4/35장이 똑바로 서고 또렷해졌습니다.
