# 한일 포털 — 안드로이드 앱

회사 포털을 **주소창 없는 앱 하나**로 엽니다. 자료는 전부 포털에 있고, 앱은 화면만 보여 줍니다.

## 폰 화면 (작은 화면에 맞춤)

- **첫 화면은 폰용 `/m`** — PC 첫 화면 대신 결재·메일·메신저·명함첩 큰 카드(한 줄에 둘) + 자주 쓰는 메뉴(한 줄에 셋).
- **아래 탭**(엄지가 닿는 자리): 🏠 홈 · ✅ 결재 · 💬 메신저 · 🔔 할 일 · ☰ 메뉴 — 새 것이 있으면 빨간 숫자.
- **☰ 메뉴** — 포털의 전체 메뉴(쓸 수 있는 것만)를 묶음별 큰 줄로, 맨 위에 찾기 칸. 맨 아래 「PC 화면으로 보기」.
- 오른쪽 아래 둥근 단추 무더기(검색·알림·도움말·메모)는 앱에서 감춥니다 — 아래 탭이 그 일을 합니다.
- 이 손질은 **앱 안에서만** 합니다(`assets/mobile.js`). 포털 자료·PC 화면은 그대로입니다.

## 하는 일

- **주소를 스스로 고릅니다** — 회사 와이파이면 사내 서버 `192.168.1.30:8820`, 밖이면 `work.hanil-steel.com`.
- **로그인 유지** — 로그인 화면의 「로그인 유지」를 저절로 켜고, 앱을 닫아도 로그인이 남습니다.
- **카메라** — 포털 화면이 QR·바코드를 찍을 때 카메라를 씁니다. 사진 올리기에서 바로 찍을 수 있습니다.
- **내려받기** — 엑셀·PDF 를 폰의 「다운로드」 폴더에 저장합니다(화면이 만든 파일도).
- **인쇄** — 포털의 인쇄 단추가 안드로이드 인쇄(와이파이 프린터·PDF 저장)로 이어집니다.
- **새 창** — 미리보기·인쇄 창은 앱 안에 덮어 뜹니다(✕ 닫기).
- **바깥 링크** — 전화·문자·메일·카카오·다른 누리집은 폰의 앱으로 엽니다.
- 아래로 당기면 새로 고침, 뒤로 가기 두 번이면 닫힙니다. 연결이 안 되면 우리말 안내와 「다시 시도」.
- ⚠ 사내 서버만 http 를 허락하고, 바깥은 https 만 씁니다.

## 만들기

    cd android
    ./gradlew assembleRelease
    # → app/build/outputs/apk/release/app-release.apk

- 안드로이드 SDK(`ANDROID_HOME`)가 필요합니다. 처음 만들 때 Google 의 `dl.google.com` 에서 빌드 도구를 받습니다.
- 서명 열쇠: `keystore/hanil-portal.jks` (비밀번호 기본값 `hanil-portal`, 환경변수 `HANIL_KS_PASS` 로 바꿀 수 있음).
  ⚠ **이 열쇠를 잃어버리면 같은 앱으로 업데이트를 못 합니다** — 따로 백업해 두세요.

## 포털에 올리기 (직원들이 받는 곳)

포털의 「📱 앱 받기」(`/app`)가 이 앱을 나눠 줍니다(꾸러미 이름 `com.hanil.portal.staff`).

1. 만든 APK 를 포털 서버의 `public/app/hanil-staff.apk` 로 둡니다.
2. 같은 곳에 `dist/hanil-staff.json` 을 `public/app/hanil-staff.json` 으로 둡니다(`code` 는 앱의 versionCode).
3. 직원들은 폰에서 포털 → 「📱 앱 받기」 → QR 또는 받기.
4. 새 판을 낼 때는 `app/build.gradle` 의 `versionCode`·`versionName` 을 올리고, 위 두 파일을 바꿔 둡니다.
   → 앱을 켜면 **「새 판이 있습니다」** 가 떠서 받기만 누르면 됩니다.

## 설치(폰)

1. APK 파일을 폰으로 옮깁니다(메일·카카오톡·NAS).
2. 열면 「출처를 알 수 없는 앱」 허용을 묻습니다 → 허용 → 설치.
3. 새 판은 같은 방법으로 덮어 설치합니다(로그인은 그대로 남습니다).
