# 🚚 한일 기사 — 안드로이드 앱

기사님 폰에 까는 **껍데기 앱**입니다. 화면은 포털(`/driver`)에서 그대로 옵니다.

## 왜 앱을 만들었나

웹(브라우저·홈 화면 아이콘)으로는 **브라우저가 막는 것**을 넘을 수 없었습니다.

| 브라우저에서 안 되던 것 | 앱이 하는 일 |
|---|---|
| 📷 카메라 — 크롬이 「차단」을 기억하면 **물어보지도 않는다** | 앱 권한 한 번이면 끝. 화면이 카메라를 달라고 하면 앱이 그 자리에서 내준다 |
| 🔑 로그인 — 「저장 공간 정리」 한 번에 열쇠가 날아간다 | 앱의 쿠키통은 앱이 지킨다(열쇠 3년) |
| 📸 사진 올리기 — WebView 는 파일 고르기를 **스스로 못 한다** | 앱이 사진 고르기·사진 찍기를 받아 준다 |
| ⬇ 내려받기 — WebView 는 이것도 못 한다 | 앱이 받아서 「다운로드」에 넣는다 |
| 🖨 `window.print()` — WebView 에서는 **아무 일도 안 난다** | 앱이 안드로이드 인쇄로 잇는다 |
| 🪟 `window.open` — 조용히 막힌다 | 앱이 창을 띄워 준다 |
| 🔫 스캐너를 블루투스로 붙이면 **화면이 다시 그려져 담아 둔 것이 날아간다** | `configChanges` 로 막았다 |
| 주소창·탭이 화면을 먹는다 · 화면이 꺼진다 | 꽉 찬 화면 · 화면 안 꺼짐 · 뒤로 가기 제대로 |

**화면을 새로 만들지 않았습니다.** 포털 판을 올리면 앱도 함께 새로워집니다 — 앱을 다시 깔 일이 없습니다.

## 굽는 법 (사람이 할 일은 단추 한 번)

1. 깃허브 저장소 → **Actions** → **기사앱 APK 굽기** → **Run workflow**
2. 5분쯤 뒤 그 실행의 **Artifacts** 에서 APK 를 받거나, 저장소 `release/hanil-driver.apk` 를 씁니다.
3. 그 APK 를 포털에 실으면(`public/app/hanil-driver.apk`) 기사님 폰이 **QR 로** 받아 깝니다.

PC 에서 직접 구우시려면 안드로이드 스튜디오로 이 폴더를 열고 `Build > Generate Signed APK` 하셔도 됩니다
(열쇠는 `keys/hanil-driver.jks`, 비밀번호는 `gradle.properties` 에 적혀 있습니다).

## 🔑 서명 열쇠에 대하여

`keys/hanil-driver.jks` 를 저장소에 함께 두었습니다.

- **왜:** 늘 **같은 열쇠**로 서명해야 새 판을 **덮어쓸** 수 있습니다. 열쇠가 바뀌면 기사님이
  앱을 **지우고 다시** 깔아야 하고, 그러면 열쇠(로그인)도 함께 날아갑니다.
- **위험:** 이 열쇠를 가진 사람은 「한일 기사」인 척하는 앱을 만들 수 있습니다.
  사내 저장소이므로 그대로 두었습니다 — **저장소를 밖에 공개하지 마십시오.**
- 플레이스토어에 올리실 생각이면 그때는 열쇠를 새로 만들고 이것은 버리시면 됩니다.

## 파일

```
app/src/main/java/com/hanil/driver/
  MainActivity.java   화면(WebView)과 카메라·사진·내려받기·인쇄·새 창
  SetupActivity.java  처음 한 번 — 서버 주소와 등록 코드 여섯 자리
  Prefs.java          폰에 저장하는 것(서버 주소 하나뿐)
app/src/main/AndroidManifest.xml   권한과 「화면 다시 그리지 않기」
app/src/main/res/                  아이콘·글자·모양
```
