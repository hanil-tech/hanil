# Turbo Fan Design — 윈도우 프로그램

AutoCAD 안에서 VBA 매크로(`Turbo_Fan_Design.dvb`)로 돌던 **터보팬 설계 프로그램**을
따로 실행하는 윈도우 프로그램(exe)으로 옮긴 것입니다.

- 입력 창 → 예비설계 → 설계결과 → 출력관리(외형도·회전차·성능곡선·데이터시트·보고서·소음진동) 흐름과
  계산식, 화면 배치는 **원본과 같습니다.**
- 도면은 지금처럼 **CAD 에 그립니다.** AutoCAD 뿐 아니라 **ZWCAD, GstarCAD, BricsCAD, progeCAD/IntelliCAD** 도
  됩니다 (모두 AutoCAD 와 같은 명령 체계라 같은 코드로 그림). 켜져 있는 CAD 를 찾아 붙고, 없으면 설치된 CAD 중에서
  골라 실행하거나 직접 켠 뒤 [다시 찾기] 를 누르면 됩니다. 마지막에 쓴 CAD 를 기억합니다.
- 출력관리 창의 **[도면 DWG 로 저장]** 으로 방금 그린 도면을 DWG 파일로 저장합니다 (CAD 의 다른 이름으로 저장).
- AutoCAD 에 **VBA 모듈(VBA Enabler)을 따로 깔 필요가 없습니다.**
- 설치가 필요 없습니다. 윈도우 10/11 에 기본으로 들어 있는 .NET Framework 4.8 로 돕니다.

## 받기

**[release/hanil-turbofan-v1.1.0.exe](../release/hanil-turbofan-v1.1.0.exe)**: 받아서 두 번 누르면 됩니다.

> 처음 열 때 파란 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요.
> 사내에서 만든 프로그램이라 서명이 없어서 그렇습니다.

## 자료 파일 — 프로그램 안에 들어 있습니다

원본은 AutoCAD 폴더 안의 `ALISP\Turbo Fan Design\` 아래 파일을 읽었습니다.
이 프로그램은 **그 파일들을 exe 안에 넣어 두었기 때문에 따로 준비할 것이 없습니다.** (`src/Bundle/`)

| 폴더 | 내용 |
|---|---|
| `Data\fandata.dat`, `hs2002p.dat` ~ `hs2008p.dat` | 설계 계수, 극수별 모터 자료 |
| `Data\방진카타로그.pdf` | 방진 카탈로그 |
| `Pics\*.bmp` | 회전·토출·모터 방향 그림 16장 |
| `Acad\dFanBox.dwg`, `iFanBox.dwg`, `pertable.dwg` | 도면 틀(표제란), 성능곡선 표 |
| `Word\*.dot` | 데이터시트·보고서·소음진동계산서 서식 |

**어느 자료를 쓰는지:** PC 에 `ALISP\Turbo Fan Design` 폴더가 있으면 그것을 씁니다(자료를 고쳐 쓰고 있다면 그대로 반영).
찾는 곳: exe 옆 → 실행 중인 AutoCAD 폴더 → 설치된 AutoCAD 폴더들 → `Program Files\Autodesk` 아래 → `C:\`, `D:\` 바로 아래.
없으면 exe 안의 자료를 `%LOCALAPPDATA%\Hanil\TurboFanDesign\<버전>\Turbo Fan Design` 에 풀어서 씁니다.

자료를 바꾸려면 `src/Bundle/` 의 파일을 바꾸고 다시 빌드하세요.

## 원본과 달라진 점

계산과 도면은 그대로 두었고, 바뀐 것은 아래뿐입니다.

- **입력 오류가 끝없이 반복되던 것**: 풍량을 비운 채 회전차 번호 칸에 들어가면 오류 창이 뜬 뒤 그 칸으로
  다시 들어가 같은 오류가 계속 날 수 있었습니다. 이제는 오류 창 뒤에 풍량 칸으로 갑니다.
- **오류가 나도 프로그램이 멈추지 않습니다.** 원본은 "런타임 오류" 창과 함께 매크로가 멈췄습니다.
  이제는 메시지만 보여 주고 계속 쓸 수 있습니다.
- **창 크기 조절**: 창 가장자리를 끌거나 최대화하면 칸·글자·그림이 같은 비율로 커집니다.
  마지막 크기를 기억해서 다음에도(다른 창도) 그 크기로 엽니다.
- **방향 그림**: `Pics\RH-L.bmp` 같은 그림 파일이 있으면 그것을, 없으면 같은 뜻의 그림을 직접 그려서
  보여 줍니다 (회전 방향·토출 방향·모터 위치에 따라 바뀜). 원본은 파일이 없으면 오류로 멈췄습니다.
- **자료 파일 첫 줄**: `fandata.dat` 첫 줄의 제목("Ns,ku,sigma,delta")을 원본처럼 0 으로 읽습니다
  (.NET 그대로면 여기서 오류가 납니다).
- **날개수가 반영 안 되던 것**: 원본은 날개수 칸에서 Enter 를 눌러야만 날개수가 저장되어, Enter 없이
  [설계결과]를 누르면 날개수 0(또는 이전 값)으로 응력·소음·회전차 도면이 계산됐습니다. 이제 항상 반영됩니다.
- **모터직결 Log(0) 오류**: 원본에 "에러발생 추후에 고칠것, 직결에서" 라고 적혀 있던 곳. 모터직결에서 예비설계 값이
  아직 없을 때 날개수 칸에 들어가면 런타임 오류가 났습니다. 이제 안내 메시지만 보여 줍니다.
- **CAD 연결 질문이 끝없이 뜨던 것**: CAD 가 없을 때 [아니요] 를 눌러도 원본 도면 코드가 오류를 무시하고 계속
  진행해서 같은 질문이 계속 떴습니다. 이제 도면 단추를 누를 때 한 번만 확인하고, 취소하면 그 작업을 멈춥니다.
- **선 종류 파일**: CAD 마다 이름이 달라(acadiso.lin, zwcadiso.lin, gcadiso.lin …) 차례로 찾아 불러옵니다.
- **Tab 으로도 계산**: 화면 안내("Tab Key 나 Enter Key")대로, 값을 넣은 칸에서 Tab 을 눌러도 Enter 와 같이
  계산합니다 (예비설계 회전차 번호 등).
- **전각 숫자**: 한글 입력기로 넣은 `３００` 같은 숫자를 `300` 으로 바꿔 받습니다
  (안 그러면 "숫자가 아닙니다" 오류가 났습니다).
- 글자가 칸보다 길면 잘리지 않게 칸을 늘리고, 테두리 제목과 안쪽 단추가 겹치지 않게 했습니다.
- 창의 [X] 를 누르면 프로그램이 끝납니다 (원본도 매크로가 끝났음). [설계종료]·[X] 모두 AutoCAD 연결을
  정리한 뒤 끝냅니다.

## 폴더 구성

```
turbofan/
  original/Turbo_Fan_Design.dvb   원본 그대로
  original/vba/                   .dvb 에서 꺼낸 VBA 원문 (모듈 34개, 약 14,000줄)
  src/Converted/                  VB.NET 으로 옮긴 코드 (원본과 줄 단위로 비교 가능)
  src/Forms/                      화면 배치 (원본 폼에서 위치·크기·글꼴을 그대로 읽어 만듦)
  src/Runtime/                    AutoCAD 연결, VBA 함수·폼 컨트롤 호환 부분 (손으로 쓴 것)
  tools/                          .dvb → VB.NET 변환기
  tests/                          가짜 AutoCAD 로 모든 기능을 돌려 보는 시험
  build.sh                        exe 만들기
```

## 고치는 법

- **계산식이나 도면을 고칠 때**: `src/Converted/` 의 해당 파일을 직접 고친 뒤 `./turbofan/build.sh`.
  파일 이름이 원본 모듈 이름과 같습니다 (`Calculation.vb`, `FanDraw.vb`, `cFanCasing.vb` …).
- **변환기를 고쳐서 처음부터 다시 옮길 때**: `python3 turbofan/tools/vba2vb.py`.
  `src/Converted/` 와 `src/Forms/` 를 다시 만드니 직접 고친 내용은 사라집니다.
- **시험**: `./turbofan/build.sh --test`. 입력 → 예비설계 → 설계결과 → 모든 도면(V벨트 6방향, 직결,
  회전차, 성능곡선) → 소음진동 → 뒤로 가기까지 화면 순서대로 돌리고, 그려진 도면을 SVG 로 남깁니다.
  자료는 `src/Bundle/` 의 원본 자료를 씁니다.

## 확인하지 못한 것

여기(리눅스)에는 AutoCAD 와 Word 가 없어서 아래는 **실제 PC 에서 확인이 필요합니다.**

- 실제 CAD 에 그렸을 때 원본과 같은 도면이 나오는지 (AutoCAD 외 CAD 는 COM 명령 일부가 다를 수 있음) (가짜 AutoCAD 로는 외형도·회전차·성능곡선이 모두
  끝까지 그려지고 모양도 맞는 것을 확인했습니다)
- 데이터시트·설계보고서·소음진동계산서 (Word 서식 `.dot` 에 값을 채우는 부분)
- 계산값이 원본 매크로와 똑같은지 (실제 자료 파일로 끝까지 돌아가는 것은 확인했습니다)
