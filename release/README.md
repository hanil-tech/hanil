# 배포 파일

Windows 64비트용입니다. **받을 파일은 하나씩, 그게 전부입니다.**

압축을 풀 것도, 다른 파일을 같이 둘 것도 없습니다.
설치에 필요한 모든 것이 이 파일 안에 들어 있습니다. .NET 도 따로 필요 없습니다.

## 내려받기

| 받기 | 어디에 | 크기 |
|---|---|---|
| **[① 관리 서버 설치 파일](https://github.com/hanil-tech/hanil/raw/HEAD/release/TimeGuard-Server-Setup.exe)** | 서버로 쓸 PC **한 대** | 80MB |
| **[② 직원 PC 설치 파일](https://github.com/hanil-tech/hanil/raw/HEAD/release/TimeGuard-Setup.exe)** | 시간을 제한할 **직원 PC 들** | 67MB |

②번 파일은 메신저나 USB 로 직원 PC 에 그대로 보내시면 됩니다.

> **파일이 안 열릴 때**
> · 파란 화면으로 "Windows의 PC 보호" → **[추가 정보]** → **[실행]**
> · 그래도 안 되면 파일 오른쪽 클릭 → **[속성]** → **[차단 해제]** 체크 → **[확인]**
>
> 사내에서 만든 프로그램이라 서명이 없어서 그렇습니다.

## 설치 순서

### 1단계 — 관리 서버 (먼저)

서버로 쓸 PC 에서 **`TimeGuard-Server-Setup.exe` 더블클릭**

1. 관리자 권한을 물어보면 **[예]**
2. **[설치]** → 암호화 체크와 포트는 그대로 두고 **[설치 시작]**
3. 끝나면 접속 주소와 임시 비밀번호가 나옵니다 → **[주소·비밀번호 복사]**
4. **[관리 화면 열기]** 로 브라우저가 바로 열립니다

브라우저에서:

1. `admin` 과 임시 비밀번호로 로그인
2. **[설정]** → 비밀번호 변경
3. **[기본 시간표]** → 허용 시간대 지정 (예: 월~금 `09:00-18:00`)

### 2단계 — 직원 PC

직원 PC 에서 **`TimeGuard-Setup.exe` 더블클릭** → **[설치]**. 끝입니다.

**등록 키도, 서버 주소도 입력하지 않습니다.** 설치된 PC 가 사내망에서
서버를 찾아 스스로 자기를 알립니다.

여러 대를 자동으로 설치할 때만 명령줄을 씁니다.

```
TimeGuard-Setup.exe /설치
```

### 3단계 — 서버에서 승인

서버 웹 화면의 **[새 PC 승인]** 에 방금 설치한 PC 가 나타납니다.
메뉴 옆 빨간 숫자가 기다리는 대수입니다.

PC 이름과 확인 문자(8자리)가 설치 화면에 나온 값과 같은지 보고 **[승인]** 을
누릅니다. 여러 대는 **[모두 승인]** 으로 한 번에 처리합니다.

승인한 순간부터 시간표가 적용되고 **PC 목록** 으로 옮겨 갑니다.
모르는 PC 는 **[거절]** 하십시오. **승인 전에는 어떤 정책도 내려가지 않습니다.**

## 제거

설치할 때 쓴 같은 파일을 다시 실행해 왼쪽 아래 **[제거]** 를 누릅니다.

직원 PC 를 제거하면 잠겨 있던 Windows 계정이 풀리고,
막아 두었던 원격 접속 설정도 되돌아갑니다.

## 메신저가 exe 첨부를 막는다면

`./build/publish.sh` 를 실행하면 `dist/` 에 같은 파일을 zip 으로 감싼 것도
함께 만들어집니다.

## 설치 후 꼭 해야 할 한 가지

TimeGuard 의 보호는 **직원 계정이 일반 사용자일 때** 제대로 듣습니다.
직원 계정에 관리자 권한이 있으면 서비스를 멈춰 전부 무력화할 수 있습니다.

서버 **PC 목록** 화면이 어느 PC 가 아직 위험한지 빨갛게 알려 줍니다.
표시된 PC 들의 계정 권한을 낮춰 주십시오.

방법은 `docs/직원계정_권한낮추기.md` 에 정리되어 있습니다. PC 한 대에 10분이면 됩니다.

> 그 문서의 **2단계(관리자 계정 먼저 확보)** 를 건너뛰지 마십시오.
> 건너뛰면 그 PC 에서 아무것도 못 하게 됩니다.

## 서버 없이 쓰기

PC 한두 대만 관리한다면 직원 PC 파일만 설치하고 승인을 건너뛰면 됩니다.
그 경우 `TimeGuard.Admin.exe` 메뉴에서 직접 시간표를 설정합니다.
