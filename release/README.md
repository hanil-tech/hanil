## 왜 저장소 안에 두지 않나

설치 파일 둘을 합치면 200MB 가 넘습니다. 구울 때마다 저장소에 커밋하면
저장소가 금세 수 GB 가 되고, **한 번 들어간 것은 지워도 줄어들지 않습니다.**
Releases 에 올리면 주소는 늘 같으면서 저장소는 커지지 않습니다.
