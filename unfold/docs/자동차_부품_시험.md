## 시험하면서 찾아 고친 것

| 문제 | 원인 | 고침 |
|---|---|---|
| 후드 전개 125 초 · 56 만 개 삼각형 | 촘촘한 B-스플라인을 목표 처짐으로 바로 메시 | 성근 메시에서 시작해 4 만 개 안에서 촘촘하게 (2~16 초) |
| 후드: 원스텝을 못 하고 ARAP 결과 (두께 −12 ~ +21 % 로 틀림) | 가장자리 바늘 삼각형 (가장 작은 각 0.01°) 이 ARAP 에서 뒤집힘 | 시작 블랭크에서 뒤집힌 삼각형도 용수철로만 잡고 원스텝 진행 |
| 휀다 트림선이 60 % 늘었다고 나옴 | 누르개·다이 R 저항 (1.24 등가 외력) 이 경계를 **따라** 당겨, 가파른 벽 트림선에서 블랭크 경계가 쪼그라듦 | 저항을 경계에 **수직**한 성분에만 (끌려 들어오는 방향) → 1.5 % |
| 깊은 오일 팬: 원스텝을 못 함 (삼각형 2/3 가 가장 작은 각 < 1°) | 긴 모서리를 모두 나누는 방식이 바늘 삼각형의 긴 두 변을 같이 나눠 바늘을 늘림 (336 → 15,456), 델로네 뒤집기는 방향 버그로 한 번도 안 뒤집힘 | Rivara 가장 긴 모서리 나누기 + 델로네 뒤집기 고침 → 바늘 4.7 % |
| 깊은 상자에서 프레스 방향을 못 찾음 → 금형 작용·드로잉 판정 빠짐 | 벽이 넓으면 Σ A·n / ΣA 가 0.3 아래 | 기준 0.08 (관·닫힌 꼴만 제외) |
| 사각 드로잉을 둘레 드로잉비 (β 1.6) 로만 보아 "한 번 가능" | 상자는 귀가 원통 컵처럼 가장 어려움 | **깊이 ≤ 6 × 귀 R** (MetalForming 경험식, 2014 판 7~12 배 — 보수적으로 6), 귀 R ≥ 5 t, 넘으면 재드로잉 공정 (DR1…) 추가 |
| 가장자리 늘림 계산이 짧은 경계에서 오류 | 창 인덱스 범위 | 고침, 창을 둘레 10 mm (10 t) 길이로 |

## 한계

- 원스텝 (한 번에 성형) 해석이라 실제 금형의 **바인더·애드덴덤 (덧살)·드로잉 비드** 가 없다. 외판은 실제로 덧살에서 2~3 % 이상 늘려
  강성을 주므로, "늘림 부족" 이 넓게 나오는 것은 제품 면만 본 결과다 — 금형 설계 때 덧살·비드로 늘림을 만든다.
- 후드 모서리의 작은 빨간 점은 시험 모델 모서리 (두 플랜지가 만나는 곳) 의 형상이고, 실제 후드는 모서리 R 과 헤밍으로 다르다.
- 휀다 모델은 바퀴 아치 플랜지·헤드램프 쪽 깊은 성형이 없어 실제보다 쉽다. 실제 도면 (STEP) 으로 다시 확인할 것.
