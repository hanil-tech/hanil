# 📕 한일 PDF 리더 (pdfreader)

PDF-XChange Editor 와 비슷한 모양의 PDF 리더·편집기입니다. 제작: **한일특장(주)**
인터넷과 서버가 없어도 되고, **파일은 PC 밖으로 나가지 않습니다.**

## 프로그램 하나 — 세 가지 일

**받기: [hanil-pdf-v1.6.1.exe](https://github.com/hanil-tech/hanil/raw/claude/magical-pascal-b2ksp0/release/hanil-pdf-v1.6.1.exe)** (29MB · 두 번 누르면 설치, 관리자 권한 없이)

| | 하는 일 |
|---|---|
| ① **PDF 창** | 보기 · 폴더째 검색 · 주석(도형·글·스탬프·이미지·강조) · 페이지 구성 · 변환. 탐색기에서 PDF 를 두 번 누르면 이 창으로(기본 앱 지정 후) |
| ② **크롬·엣지** | 웹에서 연 PDF(포털 첨부 등)도 브라우저 안 뷰어 대신 **이 프로그램으로** — 브라우저 설정에서 「PDF 다운로드」를 한 번 켜면 됩니다(환경 설정 → 파일 연결에 방법 안내) |
| ③ **탐색기 미리 보기** | 미리 보기 창(Alt+P)에서 쪽 넘겨 보기 · 큰 아이콘에 첫 장 그림 |

제작사 **한일특장(주)** 가 제목줄·정보 창·파일 메뉴·「앱 제거」 목록·저장한 PDF 의 「PDF 변환기」에 표시됩니다.
설치가 안 되는 PC 에서는 프로그램의 **파일 → 내보내기 → 브라우저용 파일**로 만든 html 한 장을 크롬·엣지로 엽니다(기능은 같음).

### 윈도우 프로그램 설치·지우기

1. `hanil-pdf-v1.6.1.exe` 를 두 번 누릅니다(「Windows의 PC 보호」가 뜨면 **[추가 정보] → [실행]** — 서명 없는 사내 프로그램이라 그렇습니다).
2. `%LOCALAPPDATA%\Programs\HanilPDF` 에 깔리고 창이 뜹니다. 처음 한 번 「기본 프로그램으로」를 누르면 윈도우 설정이 열립니다 →
   **.pdf 의 앱을 「한일 PDF 리더」로** 고르세요(윈도우 10·11 은 프로그램이 기본 앱을 마음대로 못 바꿉니다).
3. 탐색기에서 PDF 를 고르고 **Alt+P**(미리 보기 창) — 쪽을 바퀴로 넘겨 봅니다. **보기 → 큰 아이콘·아주 큰 아이콘** 에서는 PDF 마다 첫 장이 그림으로 나옵니다.
   - 기본 앱이 엣지·아크로뱃이어도 그림이 나오게, 그 앱 쪽에도 그림 처리기를 답니다(사용자 단위 · 지우면 되돌림).
   - 「항상 아이콘만 표시(미리 보기 안 함)」이 켜져 있으면 끕니다. 그래도 옛 아이콘이 보이면 탐색기 창을 닫았다 다시 여세요.
4. **자동 업데이트(1.6.0 부터)** — 켤 때와 6시간마다 저장소의 `release/hanil-pdf.json` 을 읽어, 새 판이면 뒤에서 받아
   크기·SHA-256 을 맞춰 본 뒤 깔아 둡니다. 창 아래에 「새 판 v… — 지금 다시 시작」이 뜨고, 그냥 두어도 다음에 켤 때 새 판입니다.
   끄기·지금 확인: **환경 설정 → 정보·업데이트**, 또는 **도움말 → 업데이트 확인**. (1.5.0 이하는 1.6.0 을 한 번 손으로 깔아야 합니다.)
   새 판 올리기: `package.json` 의 `version`(+`updateNotes`)을 올리고 `build-all.sh` → `release/hanil-pdf-v<판>.exe` 와 `release/hanil-pdf.json` 을 **같은 커밋**으로 push.
   새 exe 를 받아 두 번 눌러도 그대로 덮어 설치됩니다. 지우기: **설정 → 앱 → 한일 PDF 리더 → 제거**.

- 창은 윈도우에 들어 있는 **WebView2(엣지 엔진)** 로 그립니다. 없으면(아주 오래된 윈도우 10) 기본 브라우저로 엽니다.
- 이미 떠 있을 때 PDF 를 또 두 번 누르면 **그 창의 새 탭**으로 열립니다.
- 창을 닫을 때 저장하지 않은 문서가 있으면 묻습니다.
- 탐색기 미리 보기는 `hanil-pdf-preview.dll`(C, 이 저장소) + `pdfium.dll`(구글 PDFium, BSD) — 탐색기가 따로 띄우는 미리 보기 프로세스에서 돕니다.

### 크롬·엣지에서 PDF 열기

- **크롬**: 설정 → 개인 정보 보호 및 보안 → 사이트 설정 → 추가 콘텐츠 설정 → PDF 문서 → 「PDF 다운로드」
- **엣지**: 설정 → 쿠키 및 사이트 권한 → PDF 문서 → 「항상 PDF 파일 다운로드」 켜기
- 그 뒤 웹 PDF 는 내려받아지고, 누르면 기본 PDF 프로그램(한일 PDF 리더)으로 열립니다. 고쳐서 저장하면 내려받은 그 파일에 저장됩니다.
- ⚠ 1.6.0 까지는 프로그램이 브라우저 정책(AlwaysOpenPdfExternally)을 직접 켰지만, 백신이 「브라우저 변조」로 보는 동작이라 1.6.1 부터 하지 않습니다.
  예전 판이 켠 정책은 환경 설정 → 파일 연결 → 「예전 판이 켠 브라우저 정책 끄기」로 끕니다(켜 두어도 문제는 없음).
- (참고) 브라우저 안에서 바로 보는 크롬 확장도 `pdfreader/src/chrome` 에 있습니다(`out/chrome` 로 만들어짐) — 회사 웹 스토어 등록이 필요해 기본 배포에는 넣지 않았습니다.

### ✏️ 고친 것은 PDF 표준 주석으로 — 상용 프로그램에서도 그대로

넣은 도형·글·스탬프·그림·강조는 PDF 표준 주석(Square·Circle·Line·Ink·FreeText·Stamp·Text·Highlight·Underline·StrikeOut)에
**모양(AP)** 을 붙여 저장합니다. 그래서

- **Acrobat·PDF-XChange·엣지·크롬에서 똑같이 보이고, 그 프로그램에서 옮기고 지우고 고칠 수 있습니다.** 주석 목록에는 환경 설정의 작성자 이름이 나옵니다.
- 거꾸로 **그 프로그램들이 넣은 같은 종류의 주석도 이 리더에서 고칠 수 있습니다**(사각형·원·선·잉크·글상자·메모·강조·스탬프 그림).
- 페이지 회전·삭제·추출·붙여넣기·자르기·워터마크·페이지 번호는 PDF 자체를 바꿉니다(저장해야 파일에 남음 · [되돌리기] 10번까지).
- ⚠ 글자 고치기는 **한 조각(한 줄 안의 글자 덩어리)씩** 바꿉니다. 문단을 다시 흘리지는 않고, 폼(XObject) 안의 글자·세로·기운 글자는 아직 안 됩니다(그때는 흰 상자로 덮고 새로 씀).
- ⚠ 전자 서명은 .pfx·.p12 인증서로 합니다 — 공동인증서(NPKI, SEED 암호)는 아직 안 됩니다. 서명한 뒤 고쳐 저장하면 서명이 깨집니다(덧붙여 저장(증분)을 하지 않음).
- ⚠ 암호(보안)가 걸린 PDF 는 보기·찾기·인쇄만 됩니다.
- ⚠ 넣지 않은 것: AI 도우미(PDF-XChange 11 의 새 기능 — 바깥 AI 서버가 필요), OCR(스캔 글자 읽기), 암호 걸기, Word·Excel → PDF.

### 검색이 놓치지 않게 한 것

도면 번호(예: `40396607-5`)를 PDF 여러 개에서 찾는 데 맞췄습니다.

- **띄어쓰기·줄바꿈 무시(기본으로 켜짐)**: 표 칸에서 `40396607` 과 `-5` 가 따로 떨어져 있거나 `4039 6607-5` 처럼 띄어 써도 찾습니다.
  끄려면 [옵션(P)…] → 「띄어쓰기·줄바꿈 무시」.
- **전각 글자**: `４０３９６６０７－５` 도 같은 글자로 봅니다(NFKC). 대/소문자는 기본으로 가리지 않습니다.
- **한글 PDF**: 글꼴을 품지 않은 한글 PDF(KSC·UniKS 글꼴 표)도 읽습니다. 글꼴 표를 파일 안에 넣어 두었습니다.
- **찾지 못하는 PDF는 따로 알려 줍니다**: 암호가 걸린 것, 깨진 것, **글자가 없는(스캔한 그림) PDF** 는 「⚠ 찾지 못하는 문서」에 이름과 함께 나옵니다.
  스캔 PDF 는 글자가 아니라 그림이라 어떤 리더로도 글자 검색이 안 됩니다(OCR 이 필요합니다).
- 옵션: 대/소문자 구분 · 단어 단위 · 여러 낱말 중 하나라도 · 하위 폴더 포함 · 문서마다 첫 번째만.
- 한 번 읽은 파일의 글은 기억해 두어 같은 폴더를 다시 검색하면 더 빠릅니다(창을 닫으면 잊음).

## ⚠ 알아 둘 것

- **「바이러스가 검출됨」으로 받아지지 않을 때** — 서명(코드 서명 인증서)이 없는 사내 프로그램이라 윈도우 디펜더·크롬이 의심할 수 있습니다.
  1.6.1 부터 백신이 악성 코드로 보는 동작(숨긴 PowerShell·cmd·regsvr32 실행, 브라우저 정책 바꾸기)을 모두 윈도우 함수 직접 호출로 바꿨습니다.
  그래도 걸리면 https://www.microsoft.com/wdsi/filesubmission 에 exe 를 「오진(Incorrectly detected)」으로 올리면 보통 며칠 안에 풀립니다.
  확실한 해결은 코드 서명 인증서(OV/EV)로 exe 에 서명하는 것입니다(`build-all.sh` 뒤 signtool 한 줄).

- 폴더 검색은 브라우저의 [폴더 고르기]를 씁니다. 크롬이 「이 사이트에 파일 N개를 업로드할까요?」라고 묻는데,
  크롬이 늘 쓰는 문구일 뿐 **실제로 아무 데도 올리지 않습니다**.
- 폴더가 아주 크면(수천 개) 처음 한 번은 다 읽는 데 시간이 걸립니다. 「상태」에 몇 번째를 읽는지 나오고, [중지]로 멈출 수 있습니다.
- 윈도우 프로그램은 리눅스에서 만들고 **wine(윈도우 흉내)** 으로 설치·등록·저장·탐색기 미리 보기 DLL 을 시험했습니다.
  실제 윈도우 10·11 의 창(WebView2)·탐색기 화면은 처음 깔 때 한 번 확인해 주세요.

## 만들기 · 시험

```
./pdfreader/build-all.sh          # → release/hanil-pdf-v<판>.exe (out/ 에 브라우저 한 장·크롬 확장도)
python3 pdfreader/test/make-pdfs.py /tmp/pdfs       # 시험용 PDF 폴더(한글·조각난 번호·전각·암호·스캔·깨진 것·하위 폴더)
cd pdfreader
LANG=C.UTF-8 node test/ui-check.js /tmp/pdfs /tmp/o      # 열기·찾기·폴더 검색·인쇄
LANG=C.UTF-8 node test/edit-check.js /tmp/pdfs /tmp/o    # 주석 → 저장 → pypdf·poppler(다른 프로그램)로 확인 → 다시 열어 고치기
LANG=C.UTF-8 node test/pages-check.js /tmp/pdfs /tmp/o   # 구성(회전·삭제·붙여넣기·자르기·번호·워터마크)·강조·내보내기·파일 메뉴·환경 설정
LANG=C.UTF-8 node test/chrome-check.js /tmp/pdfs         # 크롬 확장: 웹 PDF 가 이 리더로
python3 test/make-big.py /tmp/big && LANG=C.UTF-8 node test/big-check.js /tmp/big /tmp/o   # 300·1000쪽·스캔 300쪽
python3 test/make-fix.py /tmp/fix && LANG=C.UTF-8 node test/fix-check.js /tmp/fix /tmp/o   # 고친 버그(지운 쪽 남음·남의 주석·한 줄 두 칸 글자 고치기·밀린 확인 창)
# 탐색기 미리 보기 DLL: win/preview/wintest.c 를 zig cc 로 만들어 wine 에서(썸네일·미리 보기 창·등록)
```
