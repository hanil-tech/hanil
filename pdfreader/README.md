# 📕 한일 PDF 리더 (pdfreader)

PDF-XChange Editor 와 비슷한 모양의 PDF 리더·편집기입니다. 제작: **한일특장(주)**
인터넷과 서버가 없어도 되고, **파일은 PC 밖으로 나가지 않습니다.**

## 세 가지로 씁니다

| 받기 | 무엇 | 어떻게 |
|---|---|---|
| **[hanil-pdf-v1.1.0.exe](https://github.com/hanil-tech/hanil/raw/HEAD/release/hanil-pdf-v1.1.0.exe)** (20MB) | **윈도우 프로그램** | 두 번 누르면 스스로 설치(관리자 권한 없이) → 바탕 화면·시작 메뉴 아이콘 · **PDF 두 번 눌러 열기**(연결 프로그램) · **탐색기 미리 보기** · 저장하면 그 파일에 바로 |
| **[hanil-pdf-chrome.zip](https://github.com/hanil-tech/hanil/raw/HEAD/release/hanil-pdf-chrome.zip)** | **크롬 확장** | 크롬에서 PDF 주소를 열면 크롬 기본 뷰어 대신 이 리더로(포털 첨부도) |
| **[hanil-pdf-reader.html](https://github.com/hanil-tech/hanil/raw/HEAD/release/hanil-pdf-reader.html)** (4.8MB) | 브라우저 한 장 | 설치가 안 되는 PC 에서 — 더블클릭해 크롬·엣지로 |

화면·기능은 셋 다 같습니다. 제작사 **한일특장(주)** 가 제목줄·정보 창·파일 메뉴에 표시되고, 저장한 PDF 의 「PDF 변환기」에도 들어갑니다.

### 윈도우 프로그램 설치·지우기

1. `hanil-pdf-v1.1.0.exe` 를 두 번 누릅니다(「Windows의 PC 보호」가 뜨면 **[추가 정보] → [실행]** — 서명 없는 사내 프로그램이라 그렇습니다).
2. `%LOCALAPPDATA%\Programs\HanilPDF` 에 깔리고 창이 뜹니다. 처음 한 번 「기본 프로그램으로」를 누르면 윈도우 설정이 열립니다 →
   **.pdf 의 앱을 「한일 PDF 리더」로** 고르세요(윈도우 10·11 은 프로그램이 기본 앱을 마음대로 못 바꿉니다).
3. 탐색기에서 PDF 를 고르고 **Alt+P**(미리 보기 창) — 쪽을 바퀴로 넘겨 봅니다. **큰 아이콘** 보기에서는 첫 장이 그림으로 나옵니다.
4. 새 판 exe 를 받아 두 번 누르면 그대로 덮어 설치됩니다. 지우기: **설정 → 앱 → 한일 PDF 리더 → 제거**.

- 창은 윈도우에 들어 있는 **WebView2(엣지 엔진)** 로 그립니다. 없으면(아주 오래된 윈도우 10) 기본 브라우저로 엽니다.
- 이미 떠 있을 때 PDF 를 또 두 번 누르면 **그 창의 새 탭**으로 열립니다.
- 창을 닫을 때 저장하지 않은 문서가 있으면 묻습니다.
- 탐색기 미리 보기는 `hanil-pdf-preview.dll`(C, 이 저장소) + `pdfium.dll`(구글 PDFium, BSD) — 탐색기가 따로 띄우는 미리 보기 프로세스에서 돕니다.

### 크롬 확장 넣기

1. `hanil-pdf-chrome.zip` 을 풀어 둡니다(지우지 않을 폴더에).
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **[압축해제된 확장 프로그램을 로드합니다]** → 푼 폴더.
3. 끝. 웹의 PDF(주소가 `.pdf` 이거나 서버가 PDF 라고 알려 주는 것)가 이 리더로 열립니다. 도구 막대 아이콘 → 빈 리더, 링크 오른쪽 단추 → 「한일 PDF 리더로 열기」.
   - 내 PC 의 PDF(`file://`)까지 하려면 확장 **[세부정보] → 「파일 URL에 대한 액세스 허용」** 을 켭니다.
   - 크롬 기본 뷰어로 보고 싶으면 주소 끝에 `?hanilraw=1`.
   - 회사 전체에 깔려면 크롬 웹 스토어(비공개 등록)나 그룹 정책(ExtensionInstallForcelist)으로 — 포털 담당과 상의.

### ✏️ 고친 것은 PDF 표준 주석으로 — 상용 프로그램에서도 그대로

넣은 도형·글·스탬프·그림·강조는 PDF 표준 주석(Square·Circle·Line·Ink·FreeText·Stamp·Text·Highlight·Underline·StrikeOut)에
**모양(AP)** 을 붙여 저장합니다. 그래서

- **Acrobat·PDF-XChange·엣지·크롬에서 똑같이 보이고, 그 프로그램에서 옮기고 지우고 고칠 수 있습니다.** 주석 목록에는 환경 설정의 작성자 이름이 나옵니다.
- 거꾸로 **그 프로그램들이 넣은 같은 종류의 주석도 이 리더에서 고칠 수 있습니다**(사각형·원·선·잉크·글상자·메모·강조·스탬프 그림).
- 페이지 회전·삭제·추출·붙여넣기·자르기·워터마크·페이지 번호는 PDF 자체를 바꿉니다(저장해야 파일에 남음 · [되돌리기] 10번까지).
- ⚠ **원래 들어 있던 글자 자체를 고치는 것**(본문 텍스트 편집)은 하지 않습니다 — 「가리기(흰 상자)」로 덮고 「타자기」로 새로 쓰는 방식으로 고칩니다.
- ⚠ 암호(보안)가 걸린 PDF 는 보기·찾기·인쇄만 됩니다.
- ⚠ 넣지 않은 것: 디지털 서명·인증, 양식(필드) 만들기, OCR(스캔 글자 읽기), Word·Excel 로 바꾸기, 책갈피 편집.

### 검색이 놓치지 않게 한 것

도면 번호(예: `40396607-5`)를 PDF 여러 개에서 찾는 데 맞췄습니다.

- **띄어쓰기·줄바꿈 무시(기본으로 켜짐)**: 표 칸에서 `40396607` 과 `-5` 가 따로 떨어져 있거나 `4039 6607-5` 처럼 띄어 써도 찾습니다.
  끄려면 [옵션(P)…] → 「띄어쓰기·줄바꿈 무시」.
- **전각 글자**: `４０３９６６０７－５` 도 같은 글자로 봅니다(NFKC). 대/소문자는 기본으로 가리지 않습니다.
- **한글 PDF**: 글꼴을 품지 않은 한글 PDF(KSC·UniKS 글꼴 표)도 읽습니다. 글꼴 표를 파일 안에 넣어 두었습니다.
- **찾지 못하는 PDF는 따로 알려 줍니다**: 암호가 걸린 것, 깨진 것, **글자가 없는(스캔한 그림) PDF** 는 「⚠ 찾지 못하는 문서」에 이름과 함께 나옵니다.
  스캔 PDF 는 글자가 아니라 그림이라 어떤 리더로도 글자 검색이 안 됩니다(OCR 이 필요합니다).
- 옵션: 대/소문자 구분 · 단어 단위 · 여러 낱말 중 하나라도 · 하위 폴더 포함 · 문서마다 첫 번째만.
- 한 번 읽은 파일의 글은 기억해 두어 같은 폴더를 다시 검색하면 더 빠릅니다(창을 닫으면 잊음).

## ⚠ 알아 둘 것

- 브라우저 한 장(html)은 「연결 프로그램」이 될 수 없습니다 — PDF 를 두 번 눌러 열려면 **윈도우 프로그램**을 쓰세요.
- 폴더 검색은 브라우저의 [폴더 고르기]를 씁니다. 크롬이 「이 사이트에 파일 N개를 업로드할까요?」라고 묻는데,
  크롬이 늘 쓰는 문구일 뿐 **실제로 아무 데도 올리지 않습니다**.
- 폴더가 아주 크면(수천 개) 처음 한 번은 다 읽는 데 시간이 걸립니다. 「상태」에 몇 번째를 읽는지 나오고, [중지]로 멈출 수 있습니다.
- 윈도우 프로그램은 리눅스에서 만들고 **wine(윈도우 흉내)** 으로 설치·등록·저장·탐색기 미리 보기 DLL 을 시험했습니다.
  실제 윈도우 10·11 의 창(WebView2)·탐색기 화면은 처음 깔 때 한 번 확인해 주세요.

## 만들기 · 시험

```
./pdfreader/build-all.sh          # 브라우저 한 장 · 크롬 확장 · 윈도우 프로그램 → release/
python3 pdfreader/test/make-pdfs.py /tmp/pdfs       # 시험용 PDF 폴더(한글·조각난 번호·전각·암호·스캔·깨진 것·하위 폴더)
cd pdfreader
LANG=C.UTF-8 node test/ui-check.js /tmp/pdfs /tmp/o      # 열기·찾기·폴더 검색·인쇄
LANG=C.UTF-8 node test/edit-check.js /tmp/pdfs /tmp/o    # 주석 → 저장 → pypdf·poppler(다른 프로그램)로 확인 → 다시 열어 고치기
LANG=C.UTF-8 node test/pages-check.js /tmp/pdfs /tmp/o   # 구성(회전·삭제·붙여넣기·자르기·번호·워터마크)·강조·내보내기·파일 메뉴·환경 설정
LANG=C.UTF-8 node test/chrome-check.js /tmp/pdfs         # 크롬 확장: 웹 PDF 가 이 리더로
# 탐색기 미리 보기 DLL: win/preview/wintest.c 를 zig cc 로 만들어 wine 에서(썸네일·미리 보기 창·등록)
```

- `src/edit.js` — 주석(그리기·고르기·저장/읽기 = 표준 주석) · `win/app` — 윈도우 프로그램(Go) · `win/preview` — 탐색기 미리 보기(C) · `src/chrome` — 크롬 확장

- 엔진: [pdf.js](https://github.com/mozilla/pdf.js) 4.10.38 (Apache-2.0) · [pdf-lib](https://pdf-lib.js.org) 1.17.1 (MIT, 저장·페이지 구성) · PDFium(BSD-3, 탐색기 미리 보기 · `win/LICENSE-pdfium.txt`).
- `src/search.js` — 찾기(띄어쓰기 무시·전각·찾은 자리를 화면 글자 위치로 되돌리기). `src/app.js` — 화면. `build.mjs` — 한 장으로 묶기.
- ⚠ file:// 에서는 모듈 일꾼(`type: module`)을 blob 으로 못 띄웁니다(크롬). 그래서 일꾼을 보통 스크립트로 다시 묶어 넣습니다.
