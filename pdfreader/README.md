# 📕 한일 PDF 리더 (pdfreader)

PDF-XChange Editor 와 비슷한 모양의 PDF 리더입니다. **설치가 필요 없습니다.** `hanil-pdf-reader.html` 한 파일을
더블클릭하면 크롬·엣지·웨일에서 열립니다. 인터넷과 서버가 없어도 되고, **파일은 PC 밖으로 나가지 않습니다.**

**받기: [hanil-pdf-reader.html](https://github.com/hanil-tech/hanil/raw/HEAD/release/hanil-pdf-reader.html)** (4.2MB · 엔진·글꼴 표가 모두 들어 있음)

## 할 수 있는 것

| | |
|---|---|
| **열기** | [열기]·Ctrl+O · 빈 화면 두 번 클릭 · 끌어다 놓기 · 여러 개를 **탭**으로(Ctrl+Tab 으로 넘기기, 가운데 단추로 닫기) |
| **보기** | 너비 맞춤·페이지 맞춤·실제 크기·25~400%(Ctrl+바퀴는 마우스 자리 기준) · 회전 · 한 페이지 연속/두 페이지 · 전체 화면 |
| **도구** | 손 도구(끌어서 움직이기) · 텍스트 선택(복사) · 문서 안 고리(목차 → 페이지) · 이전 보기/다음 보기(Alt+←/→) |
| **탐색 창(왼쪽)** | 페이지 그림 · 책갈피(목차) |
| **🔎 찾기(Ctrl+F)** | 이 문서에서 — 찾은 곳을 모두 노란색으로, 지금 것은 주황색 · Enter 다음 · Shift+Enter 이전 · 「3 / 17」 |
| **📂 검색(오른쪽 창)** | **여러 문서에서 한 번에** — 「어디에서」: 현재 문서 · 열린 모든 문서 · **폴더 선택(하위 폴더까지)** · 파일 선택 |
| | 결과는 문서별로 「쪽 · 앞뒤 글」 → 누르면 그 문서가 열리고 **그 자리**로 감 · [목록 저장(엑셀)] |
| **속성(오른쪽 창)** | 파일 크기·쪽 수·쪽 크기(mm, A3/A4 …)·제목·작성자·만든 프로그램·날짜·PDF 판·암호화 |
| **인쇄·저장** | Ctrl+P(150dpi 로 그려 인쇄) · 다른 이름으로 저장(원본 그대로) |
| **암호 PDF** | 암호를 물어 엶(틀리면 다시 물음) |

### 검색이 놓치지 않게 한 것

도면 번호(예: `40396607-5`)를 PDF 여러 개에서 찾는 데 맞췄습니다.

- **띄어쓰기·줄바꿈 무시(기본으로 켜짐)**: 표 칸에서 `40396607` 과 `-5` 가 따로 떨어져 있거나 `4039 6607-5` 처럼 띄어 써도 찾습니다.
  끄려면 [옵션(P)…] → 「띄어쓰기·줄바꿈 무시」.
- **전각 글자**: `４０３９６６０７－５` 도 같은 글자로 봅니다(NFKC). 대/소문자는 기본으로 가리지 않습니다.
- **한글 PDF**: 글꼴을 품지 않은 한글 PDF(KSC·UniKS 글꼴 표)도 읽습니다. 글꼴 표를 파일 안에 넣어 두었습니다.
- **찾지 못하는 PDF는 따로 알려 줍니다**: 암호가 걸린 것, 깨진 것, **글자가 없는(스캔한 그림) PDF** 는 「⚠ 찾지 못하는 문서」에 이름과 함께 나옵니다.
  스캔 PDF 는 글자가 아니라 그림이라 어떤 리더로도 글자 검색이 안 됩니다(OCR 이 필요합니다).
- 옵션: 대/소문자 구분 · 단어 단위 · 여러 낱말 중 하나라도 · 하위 폴더 포함 · 문서마다 첫 번째만.
- 한 번 읽은 파일의 글은 기억해 두어 같은 폴더를 다시 검색하면 더 빠릅니다(창을 닫으면 잊음).

### 단축키

`Ctrl+O` 열기 · `Ctrl+S` 저장 · `Ctrl+P` 인쇄 · `Ctrl+W` 닫기 · `Ctrl+F` 찾기 · `F3` 다음 찾기 · `Ctrl+Shift+F` 검색 창 ·
`Ctrl++/-` 확대/축소 · `Ctrl+0/1/2` 페이지 맞춤/실제 크기/너비 맞춤 · `←/→` 페이지 · `H/V` 손 도구/텍스트 선택 · `F4` 탐색 창

## ⚠ 알아 둘 것

- 윈도에서 PDF 를 더블클릭했을 때 이 리더로 바로 열리게 할 수는 없습니다(HTML 파일이라 「연결 프로그램」이 될 수 없음).
  리더를 먼저 열고 PDF 를 끌어다 놓거나 [열기]로 엽니다. 리더 파일은 바탕 화면이나 작업 표시줄에 두면 편합니다.
- 보기 전용입니다. 주석·서명·양식 채우기·페이지 편집은 하지 않습니다.
- 폴더 검색은 브라우저의 [폴더 고르기]를 씁니다. 처음 고를 때 「이 사이트에 파일 N개를 업로드할까요?」라고 묻는데,
  크롬이 늘 쓰는 문구일 뿐 **실제로 아무 데도 올리지 않습니다**(이 HTML 은 서버가 없습니다).
- 폴더가 아주 크면(수천 개) 처음 한 번은 다 읽는 데 시간이 걸립니다. 「상태」에 몇 번째를 읽는지 나오고, [중지]로 멈출 수 있습니다.

## 만들기 · 시험

```
cd pdfreader
npm ci
npm run build                     # → out/hanil-pdf-reader.html  (release/ 에 복사해 올림)
python3 test/make-pdfs.py /tmp/pdfs                 # 시험용 PDF 폴더(한글·조각난 번호·전각·암호·스캔·깨진 것·하위 폴더)
LANG=C.UTF-8 node test/ui-check.js /tmp/pdfs        # 실제 크로미움으로 file:// 를 열어 열기·찾기·폴더 검색·인쇄 등 확인
```

- 엔진: [pdf.js](https://github.com/mozilla/pdf.js) 4.10.38 (Mozilla, Apache-2.0) — 그리기·글자 층·글꼴 표·기본 글꼴.
- `src/search.js` — 찾기(띄어쓰기 무시·전각·찾은 자리를 화면 글자 위치로 되돌리기). `src/app.js` — 화면. `build.mjs` — 한 장으로 묶기.
- ⚠ file:// 에서는 모듈 일꾼(`type: module`)을 blob 으로 못 띄웁니다(크롬). 그래서 일꾼을 보통 스크립트로 다시 묶어 넣습니다.
