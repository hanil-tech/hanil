☀️ 태양광(에너지어스 VPP) → 포털 /solar   설치 (포털 서버, gaos 계정)
   포털을 업그레이드해도 다시 붙도록: 파일은 포털 밖(~/solar)에 두고, 포털이 켜질 때마다 자동으로 확인해서 빠졌으면 다시 넣는다.

0) ~/.vpp-pass 가 있어야 합니다 (vpp-check.js 로 로그인 성공한 그 파일)

1) 파일 받기 (~/solar)
   cd ~/solar && B=https://raw.githubusercontent.com/hanil-tech/hanil/claude/eager-albattani-o16mo1
   for f in solar/solar-route.js solar/solar-page.html solar/vpp-client.js solar/patch-portal-solar.js solar/portal-addons.sh fax/portal/patch-faxbox-autoread.js; do curl -fsSLO $B/$f || echo "실패 $f"; done

2) 자동 확인 등록 (한 번, sudo 비밀번호)
   bash ~/solar/portal-addons.sh --install 알림받을포털아이디

3) 포털 다시 켜기
   sudo systemctl restart hanil-portal

4) 확인:  cat ~/solar/addons.log   그리고 https://work.hanil-steel.com/solar

되돌리기: bash ~/solar/portal-addons.sh --uninstall  →  sudo systemctl restart hanil-portal
