## v13.41.0-messenger-fix.diff (2026-10-11)

점검: deskmsg-check ✅41 · deskchat-check ✅57 · chat-check ✅18 · chatwait-check ✅11 · appdist-check ✅14

사용자 「핸드폰에서 메신저를 보내면 컴퓨터 화면에 아무것도 안 떠」

1. **PC 업무 쪽지함이 빨간 숫자만 바꿨다** — 새 쪽지가 오면 오른쪽 아래에 12초 동안 띄운다(누르면 그 대화가 열림).
   묻는 간격 60초 → 15초. (`server.js` DESK_SCRIPT)
2. **전체 채널 글이 쪽지함·안 읽은 수에 안 잡혔다** — 전체 채널은 회원 줄(chat_members)이 없어서
   회원 줄로만 세면 영영 0 이었다. (`deskmsg.js` dmItems, `server.js` /api/chat/unread)
3. **NOPS 알림 받는 이름이 보내는 길마다 달랐다** — 폰·메신저 화면은 NOPS 수신자명을 안 보고,
   쪽지함 답장은 `IFNULL(nops_name, name)` 이라 수신자명이 빈 글자면 **빈 이름으로** 보냈다.
   다른 화면(업무지시·연락기록)과 같은 잣대로 `chatNopsName()` 한 곳에서 고른다. (`server.js`)

4. (2026-10-11 오후) 사용자 「쪽지를 보내면 PC 화면에 쪽지가 왔습니다라고 메시지가 안 떠 · 폰으로 파일을 보내면 2개씩 가」
   - PC 쪽지 창 머리를 **「💬 쪽지가 왔습니다」**로, 창 제목 깜빡임·딩 소리·윈도 알림(https 로 열었을 때만 — 브라우저 규칙)
   - **보낸 글이 화면에 두 번 붙던 것**(서버에는 한 번): 보내고 나서 받는 것과 기다리던 길(wait)이 같은 순간 같은 글을
     받아 둘 다 붙였다 → 붙이는 순간의 마지막 번호보다 뒤의 글만 붙인다. (`public/chat.html` loadMsgs)
   - 점검 도구: deskmsg-check(15초), 옛 표(is_general 없음)에서도 비지 않게 예전 물음으로 물러선다.

시험: 두 계정으로 1:1·전체방 글을 보내 `/api/deskmsg`·`/api/chat/unread` 수가 맞는지, PC 화면에 쪽지가 뜨는지 확인함.
