# v15.71.0 도면 관리 — 「v3dUrl is not defined」 (2026-10-31)

사용자 화면: 포털 v15.71.0 → 도면 관리 → 폴더(랜드솔루션 › BOOM-4005)를 누르면 빨간 알림 「v3dUrl is not defined」.

- 포털 원본은 이 저장소에 없다(포털은 다른 곳에서 고침). `v3dUrl` 은 이 저장소 어디에도 없다 —
  포털의 도면 관리 화면(목록의 👁·🔍 단추를 그리는 곳)이 **만들지 않은 함수를 부르는 것**.
- 목록 단추가 도면 보기(viewer3d) 주소를 만들 때 쓰려던 함수로 보인다. 도면 보기 여는 주소는 (viewer3d/README.md):
  `/viewer3d/view?src=<파일 주소(인코딩)>&name=<파일 이름(인코딩)>`

## 고치는 법(포털 담당)

그 화면 스크립트 맨 위(또는 공용 스크립트)에 하나 넣는다:

```js
//  도면 보기(3D STEP·IGES · 2D DWG·DXF) 주소 — /viewer3d 가 없는 옛 포털이면 null(단추를 숨긴다)
function v3dUrl(src, name) {
  if (!src) return null;
  return '/viewer3d/view?src=' + encodeURIComponent(src) + '&name=' + encodeURIComponent(name || '');
}
```

- 부르는 곳의 인자 모양이 다르면(예: 파일 객체 하나) 그 모양에 맞춘다 — `grep -n "v3dUrl" -r public/ *.js` 로 부르는 곳을 먼저 본다.
- 확인: 도면 관리 → STEP 파일 줄의 👁(보기) → 3D 가 열리고, 빨간 알림이 안 뜰 것.
